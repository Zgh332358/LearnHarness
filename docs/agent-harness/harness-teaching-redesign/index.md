## 研究计数的含义

完成100条有来源的研究与设计对照判断，不是100次真人学习测试，也不是把工具调用次数当循环。16个案例形成127条文字观察；方法库按展现和交互组织，不以网站推荐列表替代分析。100轮候选经独立复核，有6条偏管理、重叠或总结的问题被重新对照并补强，原快照、修订日志和复核意见全部保留。部分条目是设计及证据组织约束，不宣称100条全是直接读者练习。

原教材浏览器核验与方法文字证据分开：Red Blob的单步操作实际检查成功；Seeing Theory、TensorFlow及javascript.info部分页面加载未完成，控件效果没有当作已验证。教材自身的4个实验已经另外实际操作，详见验证报告。

## 最终采用

保留完整技术内容，补局部职责与数据图、章首学习问题、两轮执行衔接和少量机制实验。9幅图中3幅为既有运行/定位图，6幅为本次新增。4个实验分别是事件步进、三层检查、输入选择、异常恢复；没有自动播放或装饰3D，不连接真实模型或餐厅服务。
