# I04 选择送入本轮的数据

方法状态：候选综合，2026 年 10 月 7 日。方法来自集合选择、表示取舍与当前输入控制的 text 观察；未操作来源页面或实现数据选择器。

## 目标问题

读者能否区分“资料存在于外部记录”“资料被整理后送入当前调用”“模型后来才获得的新结果”？也要看见压缩保留了什么、丢掉了什么。

## 最小控件

一组带来源与内容摘要的记录选择框，“查看本轮输入”按钮，以及原始记录/摘要的切换入口。旁边显示完整记录区与本轮实际输入区。只开放与问题有关的少量记录，不加入复杂拖拽编辑器。

## 前 → 操作 → 后

| 前 | 操作 | 后与应显示的解释 |
| --- | --- | --- |
| 外部记录中有任务要求、甲的错误、乙的菜单、无关评论 | 选择本轮要使用的记录 | 输入预览列出被选内容和记录 ID；未选内容仍留在外部 |
| 选择完整结果 | 切换为摘要表示 | 对照原文标出保留字段、被省略字段与未知事项 |
| 任务要求被省略 | 查看输入预览 | 明确提示当前输入缺少预算或忌口；不能保证模型仍按未见条件工作 |
| 时间停在甲查询完成之后 | 查看可选资料 | 乙尚未产生的结果不可选择；不是从未来给前一轮补答案 |
| 选择完成 | 组装本轮输入 | 展示实际送入的版本；与后续产生的新记录分别编号 |

这里的手工选择只是让读者体验输入组装。现实系统可能通过程序、检索或模型选择资料；教材不应暗示用户每轮都必须亲自勾选，也不能宣称所有上下文选择都由模型自己完成。

## Harness 迁移条件

展示具体文本、字段或引用，不只给“记忆”“上下文”两个盒子。选择后保留来源、时点与摘要版本。容量用已知计量或明确教学单位说明；不造假的 token 数字，也不把一个字固定当成一个 token。遗漏的影响可以通过结构检查显示，模型实际行为则需要真实记录支持。

## 禁止的误导

不把保存资料等同模型已看见；不把压缩等同无损转换；不把外部记忆等同重新训练模型；不把 Distill 的模型内部向量记忆迁移成 Harness 数据结构；不把只显示文本的例子解释成模型只能接收文本。

## 键盘与手机要求

选择框有内容标签与选中状态，不能只靠拖动卡片。原始/摘要切换可用按钮或标签页，并保留焦点。手机按“外部记录→选择→输入预览”的顺序呈现，来源与编号不截断。预览有纯文本或结构化列表版本，不能只在画布里显示。

## 证据边界与后续验证

来源均为 text。后续核对勾选是否准确对应预览、空集合或关键要求缺失是否有具体说明、未产生的结果是否被误提供、原文/摘要差异是否可信。输入选择控件可用，不代表所设计的检索策略已可靠。
