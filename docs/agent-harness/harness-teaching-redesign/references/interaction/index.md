# 交互方法索引

更新：2026 年 10 月 7 日。本目录按学习问题与交互方法组织，由研究包内[结构化观察记录](../evidence/observations.json)中的 R01–R16 观察综合而成。方法是可供后续研究—对照—判断使用的候选方案，不是当前教程大纲、章节数、最终采用决定或实施成果。

## 方法与用途

| 方法 | 读者需要回答的问题 | 最小操作 | 主要边界 |
| --- | --- | --- | --- |
| [I01 单步状态与事件回看](I01-单步状态与事件回看.md) | 此刻谁做了什么，下一轮依据哪里来？ | 上一事件、下一事件 | 回看不撤销动作；未来结果不能提前进入输入 |
| [I02 单条件对照与固定基线](I02-单条件对照与固定基线.md) | 只改这一项，为何分支或验收改变？ | 改一个条件、恢复基线 | 固定其他条件；模型输出不承诺确定 |
| [I03 先作预测，再看依据反馈](I03-先作预测再看依据反馈.md) | 我预期的状态是否与证据一致？ | 选择、查看依据、修正 | 反馈指具体误解，不能以得分证明理解 |
| [I04 选择送入本轮的数据](I04-选择送入本轮的数据.md) | 保存的资料哪些真进了本轮输入？ | 勾选记录、查看预览 | 外部保存不等于模型看见；摘要可能丢信息 |
| [I05 回看目标与固定起点](I05-回看目标与固定起点.md) | 原目标是什么，再试是否仍是同一条件？ | 查看目标、重置本例 | 重置、回看、恢复分开解释 |
| [I06 局部详情与证据反查](I06-局部详情与证据反查.md) | 当前结论能追到什么参数、返回与来源？ | 就地展开与收起 | 不只靠悬停；过程记录不是内部思维 |
| [I07 失败与停止分支的可见反馈](I07-失败与停止分支的可见反馈.md) | 哪种状态触发继续、等待、核对或停止？ | 选情境与动作、看依据 | 未知不等于失败；执行成功不等于业务满足 |

每篇均给出目标问题、最小控件、前→操作→后、案例与观察 ID、迁移条件、禁止的误导、键盘与手机要求，以及证据边界。多种方法可以用于同一个交互，不代表应建立七个分离的模拟器。例如一个单步记录可结合预测与就地详情。

## 证据状态

全部引用观察的 observed_mode 为 text。原站文字、控件标签或作者教学建议支持方法意图；不能证明原站交互目前可用，更不能证明本教材对非技术读者有效。本目录没有进行浏览器操作，也没有实现交互。根代理后续的实际操作记录应另行链接，不覆写文字观察为已操作。

键盘、触屏、窄屏、焦点与减少动画条目均为本项目的验收要求，不声称来源网站已全部满足。模拟需明确标注虚构资料与规则；真实调用记录需来源、时点与可核查结果。没有实测成本或成功率时不显示伪造测量数字。

## 后续采用判断

每次选择方法时，记录它对应的读者问题、哪项具体证据支持、相对静态文字增加了什么可观察关系、是否需要更多控件，以及拒绝或简化的理由。工具调用与观察条数不自动计为研究循环。本目录没有增加 100 次编号判断的完成计数。
