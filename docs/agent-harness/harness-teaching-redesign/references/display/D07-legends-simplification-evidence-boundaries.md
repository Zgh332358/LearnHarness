# D07｜明确图例、简化与证据边界

方法类型：展现（display）。综合日期：2026 年 10 月 7 日。

本文根据 16 个案例的研究记录提炼展现规格，不是现有教程大纲审阅或 HTML 实现。来源部分是已有页面观察；下面的迁移方案、排版与检查均为基于需求基线的设计推断，尚未经过目标读者实验。部分源观察属于交互，但本文只提炼它们需要怎样显示对象、数据与解释。

## 目标问题

同一种颜色、线、框到底代表什么？图中省略了什么，教学模型是否被当成真实架构，未知是否被绿勾掩盖？

## 排版与图的具体结构

1. 每种图只定义必要的编码：框表示哪个对象、实线／虚线表示何种关系、颜色表示哪类状态。图例贴近图，状态同时有文字，不要求读者记住跨章不同编码。

2. 简化前先说明要保留的关键关系，再列省略项。简化可删表现细节，却不能省略请求未执行、外部状态未知、授权或副作用这些决定机制的分界。

3. 图注标明教学归纳、真实记录、据来源改写或真实产品结构。教学数据、运行规则、资料日期与未模拟条件就近披露。

4. 图像的空间位置不代替实际部署位置；模型内部记忆图不代替外部保存记录。逻辑职责图与部署图使用不同明确说明。

5. 普通路径旁给必要边界或反例，保留“无法判断”“未取得证据”等状态。承诺范围以已证实的证据为限；一例不能说明通用可靠性。

## Harness 中适用与不适用的地方

**适用：** 适合所有流程图、部署图、当前产品对照、上下文模拟和恢复演示。它也是避免强行 3D、隐藏假设、把模拟成功当真实验证的基本约束。

**不适用：** 不适合把边界变成冗长免责声明，也不能以注明“示意”掩盖错误职责。来源图的技术内容、许可和适用范围各需核对；研究方法不授权复制原图。

## 手机与静态回退

**手机：** 图例随局部图放置，文字短而完整，状态不要只靠细小颜色块。省略与未知标记在窄屏保留，不放到只能悬停看见的提示。

**静态回退：** 转换为灰度或纯文本时，线型、文字标签和状态仍可区分。边界说明与图注一起导出，来源与核查日期不丢失。

## 使用本方法时的检查

- 任一箭头都能用一句具体传递或控制关系解释。
- 颜色去掉后，成功、失败、未执行与未知仍可区别。
- 图能说明省略什么，同时保留所有关键职责分界。

这些检查是未来教材与实现的验收要求，不是已经通过的测试。
