# D06｜学习目标、阅读路径与可判断终点

方法类型：展现（display）。综合日期：2026 年 10 月 7 日。

本文根据 16 个案例的研究记录提炼展现规格，不是现有教程大纲审阅或 HTML 实现。来源部分是已有页面观察；下面的迁移方案、排版与检查均为基于需求基线的设计推断，尚未经过目标读者实验。部分源观察属于交互，但本文只提炼它们需要怎样显示对象、数据与解释。

## 目标问题

读者知道这段读完要能做什么吗？目录能否帮助按问题找回内容，而不只是列一串技术名词？看完或按完按钮不能自动代表理解。

## 排版与图的具体结构

1. 入口先说明要解决的实际问题和推荐的初读路线，再给回查入口。目标分成应能追踪的动作、应能识别的图或数据、需要认识的少量术语。

2. 局部单元开头给一个可观察任务，例如指出执行者、配对请求与返回、判断何处仍未知。终点与开头同一问题对应。

3. 导航标签优先说明学习任务或实际作用；术语可作副标签。路径显示当前位置与下一个必要问题，不用目录数量表达学习完整性。

4. 示范先给一例，随后提供一个有最小差异的判断任务。答案说明依据和边界；如果只是阅读练习，没有自动评分，就明确呈现为自查。

5. 初读主线和回查入口分开；开放探索在相关机制已解释之后。允许随时查看目标和原始要求，不让读者靠记忆完成。

## Harness 中适用与不适用的地方

**适用：** 适合安排读者判断各方责任、状态与证据，比较本机／服务端／托管责任，或说明停止与验收。验收任务要与需求基线一致，而不是以章节数或字数计完成。

**不适用：** 不适合将全部文章游戏化成大量关卡，或把完成指定按钮顺序当唯一正确理解。LOOPY 的产品简介只证实进入方式，不能被当成完整教程学习效果。

## 手机与静态回退

**手机：** 当前位置、当前学习问题和继续入口短且清晰。导航可折叠，但正文标题与局部目标始终可见；回查不依赖悬停。

**静态回退：** 在开头给建议顺序，文中保留局部目标与自查问答，使用页内标题或页码索引。没有进度状态时仍能沿主线阅读和回到某问题。

## 使用本方法时的检查

- 每个目标能用读者实际判断或说明来验收。
- 完成按钮操作与达成学习目标分开报告。
- 回查入口能找到对象和例，而不仅是术语定义。

这些检查是未来教材与实现的验收要求，不是已经通过的测试。
