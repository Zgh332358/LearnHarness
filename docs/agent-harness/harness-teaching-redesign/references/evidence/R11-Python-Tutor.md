- 类型：interaction；观察方式：text。
- 实际观察：可视化页先给写代码和选语言区域，再给 Visualize Execution 按钮。
- 依据：[对应一手页面](https://pythontutor.com/visualize.html)。
- 迁移假设：可研究先准备输入、再显式执行的界面，突出请求与实际运行的分界。
- 限制：只读取页面结构与按钮；没有提交代码，不能声称执行成功。
