# R14｜TensorFlow Playground — A Neural Network Playground

核查日期：2026 年 10 月 7 日。研究范围：教材展现与交互方法；不是 Harness 教程定稿。

一手页面：[实际文章/产品页](https://playground.tensorflow.org/)。

## 证据状态与限制

已读取真实页面文字、控件标签和说明；未点击控件。观察交互的预期作用来自页面明示，不能写成数值变化已实测。复杂实验台不直接迁移到 Harness 主线。

所有观察的 observed_mode 都为 text（此处仅文本）。交互项记录页面明示的操作设计，不代表已经操作验证。

## 独立具体观察

### R14-O01｜播放与单步并列（interaction）

- 页面观察：页面提供重置、播放、暂停和下一步，并列显示 Epoch。
- 证据位置：页面顶端控制文字及 Epoch 标签。 [一手页面](https://playground.tensorflow.org/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：读者应能停在某一轮查看输入和结果，而不被连续动画带走。
- 限制：尚未验证控件响应；单步只是阅读控制，不能虚构一次点击就发生模型调用。

### R14-O02｜按因果方向组织实验对象（display）

- 页面观察：主界面区分 Data、Features、神经网络与 Output。
- 证据位置：页面依次出现数据、输入特征、节点说明与输出区域。 [一手页面](https://playground.tensorflow.org/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：保留输入对象、处理过程和执行结果的固定位置，减少寻找状态的负担。
- 限制：神经网络层结构不适用于 Harness；只迁移方向与对象分区。

### R14-O03｜让数据条件成为可改变输入（interaction）

- 页面观察：数据区可设训练/测试比例、噪声和批量大小。
- 证据位置：Data 区的三项输入控件标签。 [一手页面](https://playground.tensorflow.org/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：可以仅改变一个任务条件，看后续参数或分支为何改变。
- 限制：三个变量同时开放会混淆因果；非技术主线不应一次提供全部设置。

### R14-O04｜提供再生成起点（interaction）

- 页面观察：数据区有 Regenerate 按钮。
- 证据位置：数据输入后紧邻 Regenerate 控件。 [一手页面](https://playground.tensorflow.org/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：交互要能重置或换回固定起点，让读者重复对照同一机制。
- 限制：随机重生成会使实验不可直接比较；教材应优先固定样例。

### R14-O05｜局部细节按需放大与修改（interaction）

- 页面观察：页面提示悬停放大单节点输出，也提示可编辑权重或偏置。
- 证据位置：Features 后的节点与 Weight/Bias 说明。 [一手页面](https://playground.tensorflow.org/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：按需展开本轮数据字段；局部解释紧挨当前对象，不跳到另一篇术语表。
- 限制：尚未操作；鼠标悬停不应成为唯一入口，需支持触屏和键盘。

### R14-O06｜将过程指标与泛化指标分开（display）

- 页面观察：输出区分别列 Training loss 和 Test loss。
- 证据位置：Output 下有两个独立损失标签。 [一手页面](https://playground.tensorflow.org/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：可并列展示程序执行状态与任务要求是否满足，避免用一个绿色成功覆盖不同判断。
- 限制：两类损失不等于 Harness 两类成功；迁移的是指标分离而非数值定义。

### R14-O07｜对颜色编码逐项交代（display）

- 页面观察：正文分别说明数据点、连线和背景颜色所表示的量。
- 证据位置：What Do All the Colors Mean? 中分层解释。 [一手页面](https://playground.tensorflow.org/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：每种状态还应有文字；颜色含义应保持一致并贴近图例。
- 限制：原页在不同位置重复使用双色但含义不同，不能不加解释直接照搬。

### R14-O08｜允许按课题减少控件（interaction）

- 页面观察：作者提供隐藏可见功能并保存特定课题链接的说明。
- 证据位置：This Is Cool, Can I Repurpose It? 明示课题定制与链接保存。 [一手页面](https://playground.tensorflow.org/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：可以为单个学习问题只保留一个可操作条件，逐步开放相关细节。
- 限制：尚未确认具体开关；完整仪表盘会使读者先学会调参而非看懂机制。

## 不直接迁移的理由

不复制原页面的完整视觉或全部控件。只保留能服务于一个具体学习问题的方法；采用与否需要后续研究—对照—判断循环，再由根代理核查实际操作状态。复杂度、可访问性与技术等同关系均要单独判断。
