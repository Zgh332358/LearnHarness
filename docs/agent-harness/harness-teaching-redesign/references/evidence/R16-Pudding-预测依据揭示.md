# R16｜The Pudding — How Algorithms Know What You’ll Type Next

核查日期：2026 年 10 月 7 日。研究范围：教材展现与交互方法；不是 Harness 教程定稿。

一手页面：[实际文章/产品页](https://pudding.cool/2019/04/text-prediction/)。

## 证据状态与限制

已读取实际可访问文章与交互标签，未操作滑杆。该例揭示算法的预测与依据，不是让读者先提交猜测再评分的测验；不能据此声称已观察读者预测反馈。它讲早期统计预测，不能拿来代表现代 LLM 原理。

所有观察的 observed_mode 都为 text（此处仅文本）。交互项记录页面明示的操作设计，不代表已经操作验证。

## 独立具体观察

### R16-O01｜从熟悉功能进入机制问题（display）

- 页面观察：文章从手机输入建议进入文本预测与训练材料的问题。
- 证据位置：文章第一段。 [一手页面](https://pudding.cool/2019/04/text-prediction/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：先明确读者正在解释的实际行为，再拆数据和运行过程。
- 限制：生活场景只作入口，不得用输入法预测代替 Harness 的完整工作定义。

### R16-O02｜用位置控制当前可见输入（interaction）

- 页面观察：作者让读者选择账号和文本，用滑杆改变文本位置。
- 证据位置：k Nearest Neighbours 第一块的操作说明和控件标签。 [一手页面](https://pudding.cool/2019/04/text-prediction/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：逐轮展示当时已取得的信息；不要将之后的执行结果提前放进前一轮输入。
- 限制：未操作；Harness 不必用连续滑杆，离散步骤通常更清楚。

### R16-O03｜预测同时揭示所用依据（display）

- 页面观察：候选词旁列出历史中最匹配的词组。
- 证据位置：第一交互块 Best matching group of words from history。 [一手页面](https://pudding.cool/2019/04/text-prediction/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：每次下一步判断旁标出所用结果编号，读者可追溯而非只看箭头。
- 限制：这是可公开的输入依据，不应编造模型内部逐字推理。

### R16-O04｜先暴露条件限制再补充机制（display）

- 页面观察：文章说明缺少相似词组的局限，再引入频繁词与前缀限制。
- 证据位置：第一块之后的正文与两项补充。 [一手页面](https://pudding.cool/2019/04/text-prediction/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：先展示查询为空或失败会阻断什么，再解释重试或替代资料的必要性。
- 限制：不能将未知结果补成事实；后备机制的适用条件需保留。

### R16-O05｜保持输入一致比较不同条件（interaction）

- 页面观察：第二块给同一文本并列展示四个来源模型的候选。
- 证据位置：Language Model with Example Data：四列模型与同一滑杆。 [一手页面](https://pudding.cool/2019/04/text-prediction/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：比较不同 Harness 设置时固定任务与模型，突出唯一被改变的条件。
- 限制：未测控件；多列同时观看会增加负担，必要时只对照两个条件。

### R16-O06｜从观察样例转向明确度量（display）

- 页面观察：候选比较后，文章转向按正确字符比例衡量预测表现。
- 证据位置：第二块后进入 Language Model with User Data。 [一手页面](https://pudding.cool/2019/04/text-prediction/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：观察到一轮成功后，再说明如何按任务验收和运行指标评价系统。
- 限制：指标需要对应学习问题；不把字符比例迁移为 Harness 综合评分。

### R16-O07｜用例外限制概括的范围（display）

- 页面观察：文章给一个跨来源预测更好的个例，说明通常规律不是硬规则。
- 证据位置：用户数据模块后 working together with organizations 的例外说明。 [一手页面](https://pudding.cool/2019/04/text-prediction/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：指出工具正常返回仍可能不满足业务条件，避免把常见路径讲成唯一行为。
- 限制：个案只能用于反驳绝对陈述，不证明普遍概率或优势。

### R16-O08｜保留操作形式只换数据来源（interaction）

- 页面观察：后续 Friend Data 块重复账号、模型与文本选择控件。
- 证据位置：Language Model with Friend Data 模块标签。 [一手页面](https://pudding.cool/2019/04/text-prediction/)。
- 观察方式：页面文本及控件标签；尚未操作。
- 迁移假设：沿同一数据展示形式递进新条件，避免每章换一套操作与视觉语言。
- 限制：未验证重复模块同步效果；不要为重复而增设无新学习收益的交互。

## 不直接迁移的理由

不复制原页面的完整视觉或全部控件。只保留能服务于一个具体学习问题的方法；采用与否需要后续研究—对照—判断循环，再由根代理核查实际操作状态。复杂度、可访问性与技术等同关系均要单独判断。

## 根代理统一浏览器核查建议

根代理操作首个滑杆，记录文本前缀、末三词和历史匹配是否同步改变；在第二块保持同一文本比较四列候选；选不同例子查看第三块指标是否更新。
