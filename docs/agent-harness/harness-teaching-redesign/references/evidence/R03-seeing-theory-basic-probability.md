## 证据取得方式与边界

本案例只通过联网工具读取原页面文本，没有操作页面控件、没有验证图形位置和响应。以下「观察」只陈述原文可证实的界面说明或编排；「迁移判断」属于针对 Harness 教学需求的推断。原文说能拖动、切换或播放，不等于本轮已经操作成功。

只研究教材方法；未读取 DSH／learnDSH，未审阅现有 Harness 教程大纲，未制作 HTML。需要根代理统一在既有浏览器空间完成「待操作核验」。

## R03-O01｜重复结构让对象变化而阅读方式稳定

方法类型：展现（display）。证据模式：页面文本（text）。

**观察：** 本章用硬币、骰子、卡牌分别解释三种统计概念。 [原页面](https://seeing-theory.brown.edu/basic-probability/index.html)

**证据定位：** 三个概念段落及其实验说明，网页提取行 13–45。

**对应学习问题：** 读者学习新机制时，是否还要重新学一套界面？

**迁移判断：** 【推断】基础循环、失败循环、恢复循环都采用同一“输入—事件—状态—下一步”数据单，只更换关键机制。

**限制与不适用原因：** 文本顺序可证实；三段的真实布局未验。不同 Harness 机制不能靠换名称伪装成相同事件。

**待操作核验：** 比较三段控件、解释和反馈的位置，确认结构是否足够一致。

## R03-O02｜单次与批量实验并列

方法类型：交互（interaction）。证据模式：页面文本（text）。

**观察：** 硬币实验提供一次翻转与一百次翻转选项。 [原页面](https://seeing-theory.brown.edu/basic-probability/index.html)

**证据定位：** 硬币实验按钮文本，网页提取行 18–20。

**对应学习问题：** 单次结果是否会被误当成系统整体表现？

**迁移判断：** 【推断】用预先录制且标明来源的运行集合，对照一次任务与批次成功/未知/失败计数，解释评测与任务验收的区别。

**限制与不适用原因：** 未按按钮；不能报随机序列或图像。模拟多次不能证明真实产品可靠性，不能把固定演示称为实验统计。

**待操作核验：** 分别单次和批量操作，确认样本量、频率和历史如何显示。

## R03-O03｜直接修改真实分布参数

方法类型：交互（interaction）。证据模式：页面文本（text）。

**观察：** 硬币说明可拖动右侧蓝色概率条，改变硬币权重。 [原页面](https://seeing-theory.brown.edu/basic-probability/index.html)

**证据定位：** 硬币权重说明，网页提取行 21。

**对应学习问题：** 读者能否区分设定条件与一次结果，而不把输出波动怪给界面？

**迁移判断：** 【推断】教学例把可改的运行规则与只读的工具返回分开，读者改规则后看到的是相同返回下的新决策。

**限制与不适用原因：** 位置与颜色来自页面指示；未拖动验证。真实世界的未知状态不是读者可设定的概率条。

**待操作核验：** 改变概率条，确认理论概率和样本统计是否分别标明。

## R03-O04｜具体实验配定义与公式

方法类型：展现（display）。证据模式：页面文本（text）。

**观察：** 期望段紧接骰子实验，区分期望与运行样本均值。 [原页面](https://seeing-theory.brown.edu/basic-probability/index.html)

**证据定位：** 期望段，网页提取行 22–33。

**对应学习问题：** 术语定义能否对应具体可观察量？

**迁移判断：** 【推断】解释上下文容量时同时给本轮材料表和容量计算；术语、对象、数值必须能逐项对应。

**限制与不适用原因：** 文本有定义及说明；图面未验。容量可以计量，理解或质量却不能直接由占用量推出。

**待操作核验：** 操作骰子，检查理论值与样本均值是否始终可区分。

## R03-O05｜改组成条件，看聚合结果改变

方法类型：交互（interaction）。证据模式：页面文本（text）。

**观察：** 骰子各面概率条可调整，作者要求观察期望变化。 [原页面](https://seeing-theory.brown.edu/basic-probability/index.html)

**证据定位：** 骰子分布调整说明，网页提取行 33。

**对应学习问题：** 总量变化由哪些组成项造成，能否反查？

**迁移判断：** 【推断】读者选择本轮纳入的资料，材料表同步显示总占用、被排除事实和后续问题可否回答。

**限制与不适用原因：** 未调条形；实际归一化规则未知。上下文选择对答案的影响不能写成精确的概率求和。

**待操作核验：** 调整一个面，确认其他概率如何联动及总和约束怎样表达。

## R03-O06｜理论量与估计量区分

方法类型：展现（display）。证据模式：页面文本（text）。

**观察：** 方差说明将运行估计标绿色、真实方差标蓝色。 [原页面](https://seeing-theory.brown.edu/basic-probability/index.html)

**证据定位：** 方差实验说明，网页提取行 36–39。

**对应学习问题：** 读者是否能区分规则中的目标值、观测值与估计？

**迁移判断：** 【推断】结果表用文字类型标出用户要求、工具观测、模型判断和仍未知；颜色只作辅助。

**限制与不适用原因：** 配色来自原文，未检验图色与图例。Harness 通常没有可见的“真实值”，不能把模型判断标成真实值。

**待操作核验：** 抽牌，确认两量同时可读，且不只靠颜色区分。

## R03-O07｜选择样本集合而非只推滑杆

方法类型：交互（interaction）。证据模式：页面文本（text）。

**观察：** 卡牌实验让读者点选哪些卡进入牌组。 [原页面](https://seeing-theory.brown.edu/basic-probability/index.html)

**证据定位：** 牌组选取说明，网页提取行 45–47。

**对应学习问题：** 集合成员是否影响后续过程，记录存在是否等于已被送入？

**迁移判断：** 【推断】用勾选记录决定哪些事实进入下一轮；旁边同时保留完整档案和实际发送清单。

**限制与不适用原因：** 未点卡；抽取机制和空牌组行为未验。检索不总由用户手工选择，教学操作应说明它代表输入组装。

**待操作核验：** 排除部分卡，确认抽样只来自剩余集合；检查清空的边界。

## R03-O08｜学习位置与继续入口明确

方法类型：展现（display）。证据模式：页面文本（text）。

**观察：** 章末提供下载与下一章入口，页面也列章节导航。 [原页面](https://seeing-theory.brown.edu/basic-probability/index.html)

**证据定位：** 章末和导航提取内容，网页提取行 49–71。

**对应学习问题：** 读者完成当前例后能否知道去哪里，也能回到某个问题？

**迁移判断：** 【推断】阅读导航按学习任务命名，并在一段完成后提供下一任务和回到当前数据例的入口。

**限制与不适用原因：** 只核实链接文本与导航条目；未下载或验证跳转。页面显示已归档，不能把它描述为持续维护的工具。

**待操作核验：** 核验章节选择、下一章和下载的现有行为，分别记录成功或不可用。
