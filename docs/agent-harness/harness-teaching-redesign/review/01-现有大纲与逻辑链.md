## 现有依赖链

用户目标与约束 → 运行程序组织本轮输入 → 模型产生答复或请求 → 程序检查请求 → 工具实际执行 → 结果保存并选择进入后续输入 → 模型再次判断 → 继续、等待、恢复或停止 → 按业务条件验收。

第1章定义角色，第2章展开消息，第3章完成任务；第4—6章补执行与运行控制；第7—9章补信息和跨轮持久性；第10章补组织方式；第11章补连接协议与开发组件；第12章用逻辑职责、部署与开发抽象定位；第13章核对当前产品；第14章验证系统是否办好；第15章迁移与项目走查。

## 初步判断

当前技术覆盖已经较全，主要缺口是呈现证据：大量规则只用文字，读者不能就近对照当前输入、当前阶段和已知事实。现有3幅平面图承担一轮过程与系统位置，缺少信息选择、权限检查、结果未知与恢复的局部图解。需要增加章首学习问题、少量因果实验与静态机制图，不通过减少深度替代解释。独立技术和产品审阅见同目录后续文件。
