# 定稿：大纲、图文与最小交互规划

100轮研究之后编制，合并技术、产品和定位审阅结论后定稿。保留15章与3附录的技术主线，不增加新的主题层级；正文完整保留，补足局部可观察解释。

## 内容与章首导学

每章给一个问题、必要前提、读完能完成的判断。1—3章走完整任务；4—6章解释执行与控制；7—9章解释信息与恢复；10—11章解释任务组织与组件；12—13章定位；14—15章验收和迁移。附录保持回查、自测、来源。

## 阅读布局

首页导言只在第一章或全文模式出现；后续章节直接进入本章问题。完整目录、章节锚点、上一章／下一章、全文和打印继续支持。正常论证保持正文流，不把每段拆成卡片。协议数据和进阶说明可按需展开，授权、未知、错误和关键结论默认可见。

所有交互均为预设教学模拟，不接真实餐厅、模型或业务工具。原生控件支持键盘、触屏，状态同时用文字表达。静态正文与数据表使不使用交互的人也能读懂。无自动播放、无装饰3D、无伪造成功率与成本曲线。

## 独立审阅处理

技术：统一四种结束事件；执行前检查本次未知副作用；未知业务结果不叫失败；纠正丁/丙候选混写。产品：补同一Q01实际检查/执行记录，闭合Q02乙查询、返回与后续输入；每实验明确唯一变项。定位：补本地可复用Codex Harness与名称分类不是行业标准两条边界。以上采用后开始实施。
