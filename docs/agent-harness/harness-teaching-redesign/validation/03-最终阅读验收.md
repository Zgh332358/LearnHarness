## 4．新增阅读负担

源码显示正常正文仍是连续段落、表格与代码块；卡片式节点局限在机制图，实验字段属于同一次过程，没有把每段正文都拆成独立卡片。章首问题与学习目标形成入口；后续章隐藏长首页导言的逻辑也已实现。

保留两项非阻断的阅读改善建议：

1. 多个新增图前同时出现“看图问题”正文和图内同类提问，可以合并重复提示，保留图内明确问题与静态关系即可。
2. 桌面图中文字和箭头标签有较小字号，尤其第 10 章两种方式并列且节点较多。浏览器应重点看字是否易读、窄屏转纵向后是否仍需记忆远处字段；静态代码中存在响应式规则不等于视觉已通过。

第 2 章开头仍称“只追踪一次包间查询”，后面已扩展到乙的第二次反馈。可改为“从甲的一次查询开始，再看结果怎样带来后续查询”，使导言与本章范围更准确。这不影响现有机制结论。

## 5．待修项及验证边界

**待修：无 JavaScript 时，第 7 章资料勾选框仍可改变，而输入预览不能更新。** 当前 `noscript` 样式隐藏实验操作按钮等，但未禁用或隐藏 `.lab-records` 中的 checkbox。读者仍可改变勾选，却没有组装按钮或反馈更新，容易把默认预览当成新选择的结果。

建议无 JS 时禁用或隐藏这些勾选控件，同时保留五条记录文字、默认输入和解释；也可默认禁用，由脚本初始化后启用。这是源码可复现的结构问题，未实际关闭 JavaScript 操作浏览器。

静态结构核对得到 18 个阅读节、18 个章首入口、9 个 figure、4 个实验；未发现重复 DOM ID 或指向不存在 ID 的页内链接。只核对目标存在，没有点击导航或验证焦点移动。

仍需由浏览器验收确认：四实验全部路径实际更新、键盘与焦点、窄屏溢出、原生展开项与打印、无 JS 回退，以及默认分章和全文模式之间的导言与位置行为。未完成的这些项目不计作本报告通过项。
