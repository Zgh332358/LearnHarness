## 071 · 动画默认状态如何安排？

上一轮：窄屏输入→处理→结果竖排，表格可局部横滚，正文不产生整体横向溢出

证据：[R04-O01](https://ciechanow.ski/gears/)：【观察：页面文本】开头说明每图可暂停，也可全局暂停动画。；[R08-O03](https://ncase.me/polygons/)：先手动移动，再自动运行。

对照与判断：持续运动会争夺注意力，暂停也容易误认为取消真实任务。教程的核心变化适合离散状态。

决定：默认静止。新增约束：无自动播放；尊重减少动态偏好；动画暂停只解释为展示暂停

## 079 · 聚餐预算和运行预算同叫预算，怎样避免混淆？

上一轮：方法文档保留案例与观察ID，循环记录保留问题、证据、取舍和设计变化

证据：[R01-O07](https://www.redblobgames.com/pathfinding/a-star/introduction.html)：【观察：页面文本】成本段并列步数与距离，再比较两类搜索。；[R14-O06](https://playground.tensorflow.org/)：输出区分别列 Training loss 和 Test loss。

对照与判断：Red Blob把步数与距离分列，TF将训练/测试指标分开，启发按含义与单位独立显示。1800元是业务方案上限；模型费用、时间、工具次数是运行限制，不能合成一个红色超预算。

决定：分开目标与运行指标。新增约束：预算卡分别标业务总价1800元与运行限制类型，停止说明指出是哪一种限制
