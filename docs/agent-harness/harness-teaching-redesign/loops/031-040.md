# 第 031—040 轮研究判断

证据为原作者页面文字。设计约束与Harness技术规则分别说明；6条经独立复核补作具体对照，初版与修订日志保留。

## 031 · 模型上下文与保存状态怎样在图上区分？

上一轮：步进同时更新当前阶段、已知事实、事件记录；未发生的结果明确为尚未获得

证据：[R13-O02](https://distill.pub/2016/augmented-rnns/)：外部记忆段先说明记忆是向量数组，再解释读写。；[R11-O04](https://pythontutor.com/visualize.html)：Demo 分别描述调用栈中的局部变量和堆中的对象及指向关系。

对照与判断：保存在系统里的记录不等于本轮已发送给模型。图需显示两个容器及选择、取回动作，而非泛称记忆。

决定：分区并显示发送边界。新增约束：本轮输入单与保存记录表分开，选择进入输入的条目被明确列出

## 032 · 任务摘要该如何展示信息损失？

上一轮：本轮输入单与保存记录表分开，选择进入输入的条目被明确列出

证据：[R01-O03](https://www.redblobgames.com/pathfinding/a-star/introduction.html)：【观察：页面文本】页面提供门作为边和网格表示的切换选项。；[R13-O05](https://distill.pub/2016/augmented-rnns/)：翻译示例对照单个摘要向量与逐词保留的信息。

对照与判断：摘要改变表示并可能遗漏。不能像等价地图转换一样承诺原意完全保持。

决定：适配并暴露遗漏。新增约束：对照原目标与摘要，标出预算、禁忌、只查询是否保留，缺项时说明后果

## 033 · 怎样图解权限边界而不拟人化？

上一轮：对照原目标与摘要，标出预算、禁忌、只查询是否保留，缺项时说明后果

证据：[R08-O01](https://ncase.me/polygons/)：只允许移动不满意的形状。；[R12-O04](https://javascript.info/introduction-browser-events)：Possible mistakes 把函数引用与带括号的立即调用相邻对照，并解释后果。

对照与判断：可行动条件应是显式程序检查。让模型说我谨慎不能代替权限门槛。

决定：画检查而非人格。新增约束：请求之后、执行之前显示格式／语义／权限检查，并单列拒绝理由

下一轮：如何表示工具正常但任务未达成？

## 034 · 如何表示工具正常但任务未达成？

上一轮：请求之后、执行之前显示格式／语义／权限检查，并单列拒绝理由

证据：[R14-O06](https://playground.tensorflow.org/)：输出区分别列 Training loss 和 Test loss。；[R16-O07](https://pudding.cool/2019/04/text-prediction/)：文章给一个跨来源预测更好的个例，说明通常规律不是硬规则。

对照与判断：工具HTTP成功、数据返回、满足聚餐条件是不同判断，一个绿色成功会掩盖甲已满与丙未知。

决定：分开状态指标。新增约束：结果卡同时列执行状态、返回事实、业务可用性和未知项

下一轮：未知结果应使用怎样的文字与图形？

## 035 · 未知结果应使用怎样的文字与图形？

上一轮：结果卡同时列执行状态、返回事实、业务可用性和未知项

证据：[R03-O06](https://seeing-theory.brown.edu/basic-probability/index.html)：【观察：页面文本】方差说明将运行估计标绿色、真实方差标蓝色。；[R16-O04](https://pudding.cool/2019/04/text-prediction/)：文章说明缺少相似词组的局限，再引入频繁词与前缀限制。

对照与判断：未知不能假扮真实值或失败。丙空位未知与已满需要不同标签与不同后续动作。

决定：未知独立状态。新增约束：显示已知／未知字段；继续查证、追问、报告限制的选择由证据支持

下一轮：对照图需要几列？

## 036 · 对照图需要几列？

上一轮：显示已知／未知字段；继续查证、追问、报告限制的选择由证据支持

证据：[R16-O05](https://pudding.cool/2019/04/text-prediction/)：第二块给同一文本并列展示四个来源模型的候选。；[R02-O04](https://worrydream.com/ExplorableExplanations/)：【观察：页面文本】作者说明滤波器同时有六种表示，共同响应参数。

对照与判断：四到六列适合原作者的研究对象，但对本读者会增加扫描。两个条件通常足够展示关键差别。

决定：默认二列或上下对照。新增约束：只比较缺少反馈／加入反馈、允许／未允许等关键差别，手机上下排列

下一轮：图例与来源放页尾是否足够？

## 037 · 图例与来源放页尾是否足够？

上一轮：只比较缺少反馈／加入反馈、允许／未允许等关键差别，手机上下排列

证据：[R13-O08](https://distill.pub/2016/augmented-rnns/)：图注区分据论文改写的图与直接引用的图。；[R14-O07](https://playground.tensorflow.org/)：正文分别说明数据点、连线和背景颜色所表示的量。

对照与判断：图例和教学归纳身份影响即时理解，应贴近图。参考列表负责更深查证，不代替局部说明。

决定：就近标注。新增约束：每图注明箭头关系、教学简化和相关来源，正文后仍保留完整来源索引

## 038 · 纯文本时怎样替代图？

上一轮：每图注明箭头关系、教学简化和相关来源，正文后仍保留完整来源索引

证据：[R02-O06](https://worrydream.com/ExplorableExplanations/)：【观察：页面文本】作者要求静态解释成立，读者按自己的疑问再交互。；[R09-O03](https://textbooks.math.gatech.edu/ila/vectors.html#subsection-10)：Vector Algebra and Geometry 同时解释数字运算与几何构造，而非另建一套图像概念。

对照与判断：截图替代不了可复制阅读与辅助技术。关键关系应有顺序文字、表头和可读对象名称。

决定：静态语义回退。新增约束：每图配一句完整关系说明；交互配默认示例表；禁止只写如图所示

## 039 · 大篇幅文档如何维持阅读位置？

上一轮：每图配一句完整关系说明；交互配默认示例表；禁止只写如图所示

证据：[R02-O07](https://worrydream.com/ExplorableExplanations/)：【观察：页面文本】资料核查例给出指词、按 W、输入查询词的操作。；[R03-O08](https://seeing-theory.brown.edu/basic-probability/index.html)：【观察：页面文本】章末提供下载与下一章入口，页面也列章节导航。

对照与判断：用户需要全面内容，不能靠删掉深度换短页面。章内锚点与章节分页可以降低导航成本。

决定：保留完整内容配导航。新增约束：当前章、上一章下一章、章内小节入口明确；深链接刷新仍回到目标位置

下一轮：每一段都做卡片会不会更清晰？

## 040 · 每一段都做卡片会不会更清晰？

上一轮：当前章、上一章下一章、章内小节入口明确；深链接刷新仍回到目标位置

证据：[R09-O07](https://textbooks.math.gatech.edu/ila/vectors.html#subsection-9)：点与向量解释后，符号习惯放在 Remark，另一种理解放在 Note。；[R12-O02](https://javascript.info/introduction-browser-events)：首个最短示例的 HTML 带运行、打开 sandbox 入口；同类示例结果 iframe 与代码相邻。

对照与判断：独立块适合说明、例子与实验边界，不适合把连续论证切成碎片。阅读主线应保持正文流。

决定：限制卡片数量。新增约束：卡片仅用于目标、示例、关键图、互动、易错点；长解释使用正常段落
