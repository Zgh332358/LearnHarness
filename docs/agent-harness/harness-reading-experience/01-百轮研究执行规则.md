# 100 轮研究与决策规则

先冻结当前 HTML 并保存桌面观测，然后并行收集四组一手前端资料：A001–A025 排版与视觉，A026–A050 导航与阅读组织，A051–A075 交互与信息反馈，A076–A100 响应式、可访问性与验收。

来源原页实际打开后记录规范建议或作者说明。仅阅读 HTML/文本不等于看过真实渲染，更不等于操作过控件。root 统一在一个浏览器 TaskSpace 中核验代表来源及本项目。

每个问题有独立 id、source_url、evidence_summary、current_diagnosis、decision、adaptation、acceptance。收集完成后逐条归一、排重、核对来源与项目对应，完成 100 个设计判断，整理单独方法卡和 10 组循环记录。保留采取、改用和舍弃决定，不为了达到数量强塞 100 个功能。

100 轮是研究与设计闭环，不声称程序把 HTML 改了 100 次；实现集中进行、实际浏览器验收另行记录。如果源文档打不开，不以搜索摘要补作原页证据。来源不承担我们自己的审美推导，分数表只表示设计者判断。

最后以独立审阅检查数量、重复性、证据与采用范围，再验收成品、同步仓库与 README。
