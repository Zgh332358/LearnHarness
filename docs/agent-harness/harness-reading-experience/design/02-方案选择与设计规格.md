# 方案选择与设计规格

研究完成后，对同样具备清晰导航和可访问性的三个方向作比较。独立评审的加权判断为：极简白底冷蓝 8.63、暖白深墨绿 9.00、深色科技蓝 7.02（满分10）。这是设计者对本教材的适配判断，不是用户测试或“互联网最好看”排名。完整权重与分析见[独立设计评审](01-独立设计评审.md)。

## 选择：暖白编辑式阅读

选暖白纸面、中性深墨正文、少量墨绿强调。教材需要持续解释技术，读者没有编程背景；文集感可以减轻开发控制台的距离，清楚的文档导航仍用于回查。参考主题库的森林色方向，但正文保留本地系统中文无衬线，章题使用可回退的宋体/衬线，避免整书宋体、外部字体或纸张纹理。

极简白底冷蓝适合快速技术查阅，长文也可以优秀；这里采用其导航纪律。深色科技蓝在本轮会增加所有图表配色负担与控制台感，留作比较，不增加夜间主题开关。本项目按非技术读者的教材定位自行选择默认方案。

## 阅读结构

- 固定的轻量书名条提供查找和阅读设置；手机增加有文字的目录入口。
- 左侧全书目录分成五组，短名称配章号；完整章题保留在正文。
- 宽屏右侧仅放本章路线，不放解释内容；中小屏路线在章首单层展开。
- 正文、问题、机制图、预设实验分别有不同标题与间距，不把整书变卡片墙。
- 手机底栏提供当前位置、目录与下一节，避免长文中途回到页首。
- 图表保留二维关系、可选择文字、完整说明。复杂对照表局部横滚并有可见提示。

## 从100方法到实施的取舍

采用或适配90条基础方法并不意味着90个功能。许多方法落在同一套字号、边界、状态或导航实现上；保留原来有效结构也算有效设计决定。10条舍弃包含强制两端对齐、全篇衬线、装饰插画、自动换章、多层折叠、假等待、学习完成率及全段复制。

部分候选进一步收窄：本章路线收录正文h3及直接教学实验h4，不把实验字段标题当论点；四个预设仍使用熟悉的原生select，旁边列出可比较的情境；本轮只做一个主题与两档字号；术语/资料表保留完整列关系，不为手机全部改成卡片。

检索在本文件本地完成，不调用AI或外部服务。结果显示所属章与原文片段。阅读位置只代表滚动位置，不是学习完成度。实现与真正验收的范围见[最终验收报告](../validation/02-前端最终验收.md)。
