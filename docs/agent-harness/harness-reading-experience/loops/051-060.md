# 第 051–060 轮前端诊断

每轮有一个可区分的问题，使用冻结版作为诊断对象；实现阶段集中落实，不伪称改了100版网页。

## A051 · 实验内只突出下一项主要动作

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/button/guidelines)。观察：Carbon 建议建立按钮强调层级；阅读为主的页面可不设置主按钮。

当前问题：源码中 .lab button 统一白底细边框；下一事件、上一事件、重新演示的视觉权重相同。

本轮决定（调整采用）：在一个实验内突出推进、组装或判断动作，回看与重置降低强调；全页阅读工具保持克制，不把每章都当作销售落地页。

完成条件：每个当前实验最多一个高强调动作；正文中继续阅读不抢实验注意力；灰度查看也能分辨主次。

[完整方法卡](../methods/A051.md)。

## A052 · 动作文案说明作用对象

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/button/guidelines)。观察：Carbon 推荐动词与对象组成明确的按钮文字。

当前问题：“下一事件”“组装输入预览”“判断这个下一步”已有对象，但顶部“上一节/下一节”缺少目的章节提示。

本轮决定（采纳）：保留技术动作名；顶部或底部继续阅读关联下一章名称。复制、展开、重置若新增，也明确对象，避免单独的“运行”。

完成条件：不看周围说明也能判断每个按钮会推进事件、生成预览还是切换章节；窄屏不得截断重要动作词。

[完整方法卡](../methods/A052.md)。

## A053 · 章节跳转与实验动作使用各自语义

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/button/guidelines)。观察：Carbon 将触发动作的按钮与导航链接区分。

当前问题：章节底部已用链接；顶部 reader-tools 使用按钮修改 hash，其他导航又使用链接。

本轮决定（调整采用）：章节跳转优先保留可直接复制、打开的锚点链接；实验推进继续使用原生 button。若顶部仍用按钮，应保留可共享的目的地锚点。

完成条件：章节地址可复制后直达；实验动作不伪装成网页链接；键盘可独立完成两种任务。

[完整方法卡](../methods/A053.md)。

## A054 · 禁用状态同时交代前置条件

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/button/guidelines)。观察：Carbon 按钮包含交互状态；文字溢出时推荐换行而非截断。

当前问题：当前禁用按钮仅 opacity .45；回执实验的判断按钮须先选答案，读者可能只看到灰按钮。

本轮决定（调整采用）：保持原生 disabled，并在紧邻状态行提示“先选择下一步”；首尾事件交代“已到首事件/末事件”。禁用不靠颜色独立传达。

完成条件：每个不可操作状态有可见原因；长文案能换行；禁用按钮不可触发动作；仍能回到有效选择。

[完整方法卡](../methods/A054.md)。

## A055 · 四个对照条件让读者直接看到

来源：[原页](https://designsystem.digital.gov/components/select/)。观察：USWDS 将少量选项优先匹配单选，并要求 select 保留明确标签。

当前问题：检查与恢复实验都只有四个情境，却把其余三个藏在 select 里。

本轮决定（调整采用）：优先试四项竖排单选或可见情境列表；若竖排造成过长，则保留原生 select 并在上方展示四类问题的简短列表。切换只改变本地展示。

完成条件：首次进入不用打开下拉就知道有哪些对照；320–390px 下能完整读选项；切换不产生真实调用或自动判断。

[完整方法卡](../methods/A055.md)。

## A056 · 判断题的答案选项不预设正确项

来源：[原页](https://designsystem.digital.gov/components/radio-buttons/)。观察：USWDS 单选文档提醒默认值可能偏置判断，并规定 fieldset 与 legend 分组。

当前问题：恢复实验已使用 radio 与 legend，初始化没有默认答案；此正确机制应在美化时保留。

本轮决定（采纳）：不把某个答案预先勾选，不按正确性先染绿；四项采用一致文字样式，回答后再解释。

完成条件：初始 radio 均未选择；正确项位置不固定；只选中答案不会提前出现判断结果；legend 能说明选择的问题。

[完整方法卡](../methods/A056.md)。

## A057 · 整段选择文字可点，控件保持熟悉

来源：[原页](https://designsystem.digital.gov/components/radio-buttons/)。观察：USWDS 推荐选项竖排、文字标签可选择，并保持选项样式一致。

当前问题：恢复选项为 .lab-choice 包裹 label，已竖排；字号、间距仍可统一，当前没有明显整行 hover/focus 反馈。

本轮决定（调整采用）：保持原生圆形单选与完整文字标签；增加低强度整行选中边界及 focus-within，不使用模糊图标代替输入。

完成条件：点标签与点圆点结果相同；长选项逐行对齐；选中由控件和边界共同表示；键盘焦点不被背景色淹没。

[完整方法卡](../methods/A057.md)。

## A058 · 勾选记录与已组装预览明确分开

来源：[原页](https://designsystem.digital.gov/components/checkbox/)。观察：USWDS 复选框用于独立多选，文字标签须清楚表达选中和未选中含义。

当前问题：上下文实验选择改变后不会自动改预览，这是教学关键；但“选择已修改，尚未组装”的视觉位置容易被长输入块分隔。

本轮决定（调整采用）：保留多选与显式组装按钮，在预览标题旁显示短状态“选择已改变·预览未更新”；正常组装后恢复“已组装·未发送”。

完成条件：取消目标记录后预览仍不变，且旁边立即有待组装提示；按组装后才更新文本；未选资料仍被解释为外部保存。

[完整方法卡](../methods/A058.md)。

## A059 · 本地视图切换弱于正文主线

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/content-switcher/guidelines)。观察：Carbon 视图切换用于同类内容的不同视图，允许较低强调样式。

当前问题：阅读工具把全文展开与章节切换并排；实验内未来若加“图/表”视图，容易与章节导航混在同一层。

本轮决定（调整采用）：正文导航、阅读模式、实验数据选择各占清楚层级；只在相同数据有真正互补视图时采用低强调切换。拒绝把全部章节做成一排 tabs。

完成条件：读者能辨别是在改阅读模式还是改实验条件；同一数据切换不会清空答案；不出现18个并列标签挤压内容。

[完整方法卡](../methods/A059.md)。

## A060 · 解释反馈留在刚操作的位置

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/notification/guidelines)。观察：Carbon inline 反馈靠近相关对象，并持续到用户处理或消除该状态。

当前问题：实验已有下方 .lab-feedback；读者需要反复比较，不能在重设计时换成消失的 toast。

本轮决定（采纳）：判断结果与依据留在按钮附近，使用稳定的反馈区。正确、需核对、未知用文字和低强度边界说明，不弹 modal、不自动消失。

完成条件：判断后可随时重读依据；反馈不会覆盖题目；切换情境清理旧反馈，避免将上题结论带到新题。

[完整方法卡](../methods/A060.md)。
