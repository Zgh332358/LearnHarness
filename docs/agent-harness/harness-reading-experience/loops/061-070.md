# 第 061–070 轮前端诊断

每轮有一个可区分的问题，使用冻结版作为诊断对象；实现阶段集中落实，不伪称改了100版网页。

## A061 · 短状态与长教学依据分层

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/notification/guidelines)。观察：Carbon 将简短状态通知与上下文信息区分，并强调靠近关联内容。

当前问题：当前 .lab-feedback 与 .lab-status 用同样软色块，长解释和“一共几条”短状态看起来同类。

本轮决定（调整采用）：短状态用轻文字行与小标记，长依据用正文段落和清楚小标题；教学解释不受通知两行限制，避免缩字号塞入窄条。

完成条件：一眼能找到“目前显示/是否已组装”；仍能完整阅读原因和不能推断之处；状态、答案、教学说明不重复整段文字。

[完整方法卡](../methods/A061.md)。

## A062 · 只给关键边界加提示框

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/notification/guidelines)。观察：Carbon callout 应少量使用；不要堆叠，普通内容使用正文。

当前问题：章学习目标、引用、实验状态、反馈、图解释都使用不同框线或底色；容易让页面成为连续提示框。

本轮决定（调整采用）：关键任务边界保留一处提示；学习目标通过版式层级呈现，普通图解释回归正文。实验区可以有一个外框，内部不再为每个段落套卡片。

完成条件：普通段落不逐段卡片化；相邻提示区有不同职责且不重复；正文、图、实验的阅读顺序保持连续。

[完整方法卡](../methods/A062.md)。

## A063 · 即时教学计算不加入假等待动画

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/inline-loading/guidelines)。观察：Carbon 将 inline loading 用于不能立即完成的动作。

当前问题：四个实验全部由本地预设数据同步更新，不存在网络或真实执行等待。

本轮决定（舍弃）：拒绝为显得像 Agent 运行加入假旋转、假进度或人为延时。解释现实等待时展示可回看的记录状态，并写明是教学模拟。

完成条件：实验动作立即响应；没有计时后自动假装已查询/已预订；停顿动画不会被误解为现实服务正在运行。

[完整方法卡](../methods/A063.md)。

## A064 · 状态变化保持锚点和布局稳定

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/inline-loading/guidelines)。观察：Carbon 要求临时加载反馈沿用原内容的位置和对齐。

当前问题：事件切换时阶段输入和输出长度不同；重设计若让状态横幅出入，会推动按钮与主观察区域跳动。

本轮决定（调整采用）：将事件编号、负责者、动作按钮设为稳定观察位置；文本区自然扩展，不用固定高度裁掉内容。已有 aria-live 简短通知保持原位。

完成条件：相邻事件切换后按钮不随机换位；页面不主动滚回顶部；文本完整可读；状态更新不会夺走键盘焦点。

[完整方法卡](../methods/A064.md)。

## A065 · 读者不应把状态标签当成按钮

来源：[原页](https://www.carbondesignsystem.com/building-blocks/core/components/tag/guidelines)。观察：Carbon 将只读标签与可选择、可移除标签分开，避免同一标签多种功能。

当前问题：阶段、未知、通过等状态目前是文字；若新增胶囊标签，很容易与选项控件形成相同外观。

本轮决定（调整采用）：只读状态采用简短文字与细标记，不加指针、不加按钮阴影；可选择条件保留 radio/checkbox 或明确的控件外框。

完成条件：静态标签不会有点击暗示或进入 Tab 顺序；实际选项可操作性清楚；“未知”不能用弱灰表达成不存在。

[完整方法卡](../methods/A065.md)。

## A066 · 突出当前事件，保留其余步骤可读

来源：[原页](https://designsystem.digital.gov/components/step-indicator/)。观察：USWDS 当前步骤最突出，其他步骤仍应维持可读性，并显示当前数与总数。

当前问题：六事件清单目前只用加粗与下划线标记当前项；事件编号另在下方状态行。

本轮决定（调整采用）：用清楚编号、短名称、细线或低饱和底色标明当前事件；保留 aria-current=step。上一/下一按钮和步骤说明分开，避免误导为所有步都可点击。

完成条件：能快速读出“第几事件/共六个”；当前项区别不只靠颜色；剩余步骤不是禁用按钮；不虚构已完成真实操作。

[完整方法卡](../methods/A066.md)。

## A067 · 阅读位置不能冒充学习完成率

来源：[原页](https://designsystem.digital.gov/components/step-indicator/)。观察：USWDS step indicator 服务于线性过程，不适合任意顺序的交互。

当前问题：文档允许目录跳章与全文模式，顶部进度条只表示浏览位置，不测理解。

本轮决定（舍弃）：拒绝把18章画成已完成/未完成任务条或标为学习成功率；用“当前章节”“本章阅读位置”说明进度，目录支持自由回查。

完成条件：跳到附录不显示前文已掌握；刷新和滚动不被记录为测试通过；进度文字与实际计算范围一致。

[完整方法卡](../methods/A067.md)。

## A068 · 批量答案与单题展开状态保持一致

来源：[原页](https://designsystem.digital.gov/components/accordion/)。观察：USWDS 展示各项独立的 aria-expanded 状态，并提供允许多项展开的示例。批量开关是本项目的扩展推导。

当前问题：现有十道自测可逐题展开，全部答案按钮却只以自身旧状态决定下一动作；单题变化后标签可能不对应当前集合。

本轮决定（采纳）：保留各题原生 details。全部答案按钮从十题是否全部打开计算文案与 aria-expanded；监听单题 toggle，允许独立思考与统一回查。

完成条件：批量打开后手动关闭一题，按钮应变为“显示全部答案”；再次点击打开十题，批量收起恢复全部关闭。

[完整方法卡](../methods/A068.md)。

## A069 · 披露标题的触发范围与状态可预测

来源：[原页](https://designsystem.digital.gov/components/accordion/)。观察：USWDS 推荐整个披露标题可选，并为内部控件留出间距。

当前问题：details summary 使用原生标记，但样式只指定文字，不统一 hover/focus、打开后的标题位置。

本轮决定（调整采用）：保持原生 details/summary，把标题行做完整可操作区；箭头与展开状态一致，展开后标题不消失。内部复制或其他动作与标题留足间隔。

完成条件：键盘 Enter/Space 可展开；点击标题文字和标记都有效；展开不会触发内部动作；关闭后仍能定位原问题。

[完整方法卡](../methods/A069.md)。

## A070 · 表格用于比较，列和单位一致

来源：[原页](https://designsystem.digital.gov/components/table/)。观察：USWDS 推荐短表头、统一列格式，表格样式保持简单。

当前问题：正文表格已有轻表头与横线；数字、日期、状态文字未形成跨表一致规则，部分宽格容纳长段落。

本轮决定（调整采用）：只把同字段对照留在表格；中文说明左对齐，金额/可求和数值右对齐且明确单位，日期按同一格式。多段解释移到表格邻近正文。

完成条件：同一列没有混用人均与总价；表头能单独解释列含义；不添加无关排序筛选；长段落不压成密密麻麻的单元格。

[完整方法卡](../methods/A070.md)。
