# 第 091–100 轮前端诊断

每轮有一个可区分的问题，使用冻结版作为诊断对象；实现阶段集中落实，不伪称改了100版网页。

## A091 · 点击目标舒服，最低尺寸与例外明确

来源：[原页](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。观察：SC 的一般目标最低 24×24，存在间距、等效、行内、浏览器控制和必要布局等例外；44px 不是本条最低要求。

当前问题：旧阅读按钮 38px 高，实验 42px 高；相邻控件可操作但主要触控按钮还能更舒适。

本轮决定（调整采用）：主要按钮和设置入口以至少 44px 高为项目舒适目标；标签整个区域可点；不将正文行内链接强制变成大块按钮。

完成条件：量测主要按钮至少 44px 高；非行内目标满足 24×24 或记录适用例外及间距；相邻控件不叠压。

[完整方法卡](../methods/A091.md)。

## A092 · 减少运动偏好下没有装饰性位移

来源：[原页](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)。观察：prefers-reduced-motion: reduce 能识别设备上用户减少运动的选择，从而调整动画。

当前问题：旧版已使用 auto 滚动，reduce 分支仅重复该设置；新的面板动画或主题过渡不能遗漏。

本轮决定（调整采用）：默认避免持续动画；在 reduce 下取消平滑滚动、位置移动和非必要过渡；实验依然使用明确单步。

完成条件：模拟 reduce，CSS/运行结果中无非必要动画和平滑滚动；操作状态变化仍明确；不使用自动播放 3D 或跟随滚动的装饰视差。

[完整方法卡](../methods/A092.md)。

## A093 · 去掉视觉排版后仍能读出并行与归属

来源：[原页](https://www.w3.org/WAI/WCAG22/Understanding/meaningful-sequence.html)。观察：内容顺序影响意义时，正确序列应可被程序确定；CSS 视觉位置不能改变关键因果顺序。

当前问题：并行图在手机上按视觉纵排；若读者只读DOM文字或忽略样式，纵向文本可能被当成串行动作。

本轮决定（采纳）：保留DOM中并行说明与每组职责标题；关掉样式观察文字顺序，确认节点与所在Agent/工具组相邻，图注仍说明竖排不代表串行。

完成条件：禁用作者样式后，工具并行与子Agent循环两组名称和边界仍存在，读序不需依赖CSS位置或颜色。

[完整方法卡](../methods/A093.md)。

## A094 · 标题和操作名说明真实用途

来源：[原页](https://www.w3.org/WAI/WCAG22/Understanding/headings-and-labels.html)。观察：已提供的标题和标签应描述主题/用途；仅有语义标签而名称含糊，仍不能帮助定位。

当前问题：旧版每章有问题和目标，是值得保留的层次；局部表格区都叫“本节对照表”，回查时难分。

本轮决定（调整采用）：保留章节问题；工具入口直接写“阅读设置/目录/查找”等用途；给宽表区具体名称，而不是全部同名。

完成条件：从标题和控件名称列表能判断用途；没有多余空标题、跳级造成的层级歧义或无上下文的“更多”。

[完整方法卡](../methods/A094.md)。

## A095 · 表格承担比较，并保留列行含义

来源：[原页](https://design-system.service.gov.uk/components/table/)。观察：GOV.UK 用表格帮助行列比较，使用 caption 描述主题、th/scope 表明行列含义；表格不用于页面布局。

当前问题：旧版 26 张表仅 3 个 caption；93 个 th 中只有 12 个 scope。二维比较很好，但辅助技术理解线索不齐。

本轮决定（调整采用）：保留真正比较表；补具体 caption（可视觉隐藏）、列头 scope=col，明确作行头的单元格用 scope=row；不把所有表改成丢列关系的卡片。

完成条件：26 张现存表均有可确定的主题；全部列头范围明确；窄屏查看任意数据时可追溯所属列；宽表只局部滚动。

[完整方法卡](../methods/A095.md)。

## A096 · 展开/收起有原生语义和明确状态

来源：[原页](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)。观察：Disclosure 包含控制器和显示/隐藏内容；按钮模式使用 Enter/Space，并暴露展开状态。

当前问题：旧版目录、静态实验表、自测已用 details；新的阅读设置宜延续此模式，避免堆入自制点击 div。

本轮决定（调整采用）：常用轻量展开用 details/summary；自定义按钮才同步 aria-expanded/controls，避免为原生 summary 写重复且冲突的状态。

完成条件：每个展开器 Enter/Space 可切换；关状态不留下可 Tab 到的隐藏操作；打开的内容可读，名称明确。

[完整方法卡](../methods/A096.md)。

## A097 · 性能用加载、响应、稳定性分别量测

来源：[原页](https://web.dev/articles/vitals)。观察：Google 的良好体验建议为 LCP≤2.5s、INP≤200ms、CLS≤0.1，并以移动/桌面真实访问第 75 百分位评估。

当前问题：旧文件约 236KB，无运行时外部资源；这是轻量基础，但体积小不能证明三项指标已通过。

本轮决定（调整采用）：不引入字体 CDN/重框架；记录新文件体积、资源请求与可用 Performance API 样本；本地样本注明环境，不声称线上第 75 百分位。

完成条件：项目体积预算设为 350KiB（可因明确功能调整）；无外部运行依赖；采集可取得的 LCP/CLS/交互延迟，缺项标未测，不以 Lighthouse 单分数替代实测。

[完整方法卡](../methods/A097.md)。

## A098 · 打印包含全文和可读的静态实验

来源：[原页](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries/Printing)。观察：print 媒体样式可调整纸面排版，beforeprint/afterprint 可处理打印前后的界面状态。

当前问题：旧版已有显示隐藏章、展开答案和静态表的代码；此前证据为静态检查，本轮应实际打印介质观察。

本轮决定（调整采用）：打印隐藏工具栏/固定按钮，展示所有章节与静态步骤；深底色改为纸面可读样式，长代码折行；退出打印恢复原阅读状态。

完成条件：实际 print 介质或打印预览中 18 节全部显示；没有固定栏覆盖；图表/长代码无截断；关闭预览后当前章、展开状态恢复。

[完整方法卡](../methods/A098.md)。

## A099 · JavaScript 失效时仍能读完教材

来源：[原页](https://www.gov.uk/service-manual/technology/using-progressive-enhancement)。观察：渐进增强从 HTML/CSS 可用的核心开始，JavaScript 提供增强；无需复杂界面的页面不必为了框架而引入框架。

当前问题：旧版所有章初始在 HTML 中，交互有静态详情和 noscript；新增设置或导航若默认隐藏正文会破坏这项基础。

本轮决定（采纳）：无 JS 时正文和目录仍可用；实验保留静态步骤/对照表，隐藏不可用动作并解释；JS 成功初始化后才启用分页增强。

完成条件：禁用脚本重新载入，不是只删 script 后猜测：18 节可读、目录锚点有效、四个实验有静态说明；不显示无效空按钮。

[完整方法卡](../methods/A099.md)。

## A100 · 来源链接的名称说明目的地内容

来源：[原页](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html)。观察：链接用途可由文字或程序可确定的上下文理解；名称与到达页主题相呼应能帮助连续阅读。

当前问题：正文引用资料数量多，新的搜索与导航若加“这里/查看”等重复词，会让读者难判断外部资料与书内位置。

本轮决定（调整采用）：正文来源继续用作者或资料内容命名；书内导航带章题，检索结果带章名与原文片段；不改为裸URL、连续“点击这里”或纯图标。

完成条件：抽查正文一手资料链接及搜索结果，脱离周围长段仍可判断将到哪类资料；相同目的地名称不制造不同事实含义。

[完整方法卡](../methods/A100.md)。
