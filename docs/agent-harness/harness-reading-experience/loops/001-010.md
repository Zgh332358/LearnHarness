# 第 001–010 轮前端诊断

每轮有一个可区分的问题，使用冻结版作为诊断对象；实现阶段集中落实，不伪称改了100版网页。

## A001 · 先确定正文阅读字号，再缩放标题

来源：[原页](https://designsystem.gov.scot/styles/typography)。观察：官方分别列出大小屏字级，正文和辅助文字有独立角色。

当前问题：正文为17px，窄屏16px；它是可用起点，但视觉修改应先锁定正文再调封面。

本轮决定（调整采用）：正文采用桌面18px、窄屏17px作为首轮候选，用rem表达并允许浏览器放大；标题依据中文换行另行微调，不直接搬Roboto数值。

完成条件：默认与200%缩放下正文不裁切；同一章节的正文、段首和段尾字号一致；至少检查一个长段与一段中英混排。

[完整方法卡](../methods/A001.md)。

## A002 · 用实际汉字行宽，而非全局容器宽度诊断长文

来源：[原页](https://practicaltypography.com/line-length.html)。观察：作者以每行字符数判断行长，指出过长行难以回到下一行。

当前问题：main最大宽800px；按17px汉字粗估约47字，具体渲染宽度尚未测量。

本轮决定（调整采用）：把普通叙述列设为约38–40个汉字宽的候选（约40em上限），图与表允许更宽；西文45–90字符建议只作参照，不认作中文标准。

完成条件：1440px宽屏统计两段中文正文每行约32–42个全角字；393px窄屏不强制固定行长；表格保留对照关系。

[完整方法卡](../methods/A002.md)。

## A003 · 拒绝把拉丁文行距数字照搬为中文教材规则

来源：[原页](https://practicaltypography.com/line-spacing.html)。观察：作者用相同文本展示紧、适中和松行距，并建议无单位CSS行高。

当前问题：正文目前1.9，图内节点1.42；二者差异大，降低全文行高可能使图内汉字更拥挤。

本轮决定（舍弃）：拒绝直接套用作者的1.2–1.45拉丁文范围；正文先试1.8–1.9，图内1.55–1.65，按钮1.25–1.4，按用途分开而不是共用。

完成条件：中文长段无上下字形碰撞；框内箭头标签换到两行也不叠字；正文调整不以缩短页面长度为唯一通过条件。

[完整方法卡](../methods/A003.md)。

## A004 · 段落间距由样式管理，不插入空段落

来源：[原页](https://practicaltypography.com/space-between-paragraphs.html)。观察：作者把段间距视为段首缩进的替代，并用CSS margin实现。

当前问题：现有p margin为1.1em，已采用样式段距；新页面若增加容器容易产生重复间距。

本轮决定（采纳）：保留无首行缩进正文；单一prose规则管理段距，按正文、图注、提示分别设定，不添加br或空p撑版面。

完成条件：DOM中无装饰性空段；两个相邻普通段间距一致；图注与图体距离小于图与下一段的距离。

[完整方法卡](../methods/A004.md)。

## A005 · 让标题更靠近它引出的内容

来源：[原页](https://designsystem.digital.gov/components/typography/)。观察：官方要求标题上方空间大于下方，使它关联后面的正文。

当前问题：h3上2em下.7em已有方向；实验标题与外层h3共用规则又被覆盖，可能破坏一致性。

本轮决定（采纳）：为正文h3与实验内部标题分别命名样式；正文标题前距约2.25rem、后距.8rem，组件标题前距更小，不把同一数值强制到所有层级。

完成条件：普通h3到首段间距小于h3与上一段的间距；实验内部h3不产生巨大空白；各章节规则相同。

[完整方法卡](../methods/A005.md)。

## A006 · 封面可有表现力，阅读和操作保持克制

来源：[原页](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview)。观察：Carbon区分表达型与任务型字级，避免产品操作被夸张标题干扰。

当前问题：封面46px，进入章节收缩为29px，已有两种情境；工具栏仍和正文使用近似重量。

本轮决定（调整采用）：封面保留显著但不占满首屏的标题；内页书名作为安静的身份标识，章节标题为阅读焦点，按钮用任务字级，禁止每章重复大封面。

完成条件：进入第2章后首屏先看到章节问题与阅读内容；封面主标题明显高于辅助信息；工具栏文字不会视觉压过章标题。

[完整方法卡](../methods/A006.md)。

## A007 · 把散落的字号汇成少量语义token

来源：[原页](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview)。观察：Carbon用预设字号、字重、行高组合表达角色，减少随意样式。

当前问题：HTML累计出现12、13、14、15、16、17、18、19、20、22、23、25、27、29等字号和多处rem；角色重叠。

本轮决定（调整采用）：使用display/chapter/section/body/caption/ui六类语义字号；技术图另设diagram-label，禁止为每一张图追加孤立微型字号。

完成条件：样式表能映射七种用途；同一用途没有无理由的三种以上字号；章节、图注、按钮各保持跨页面一致。

[完整方法卡](../methods/A007.md)。

## A008 · 检验字体替换的视觉尺寸，而不迷信px一致

来源：[原页](https://designsystem.digital.gov/design-tokens/typesetting/overview/)。观察：USWDS说明同一标称字号在不同字体上会有不同视觉大小。

当前问题：当前系统字体栈在Mac偏PingFang、Windows偏Microsoft YaHei；源代码字号不能证明两端读感相同。

本轮决定（调整采用）：继续用本地系统字体保持独立HTML，但对中文、Harness/API英文、数字与等宽代码选实际样本；不引入只覆盖西文的品牌字体作为正文核心。

完成条件：检查可用Mac字体与一个明确的替代字体；标题和代码无缺字、无明显基线错位；记录未实测平台而不是宣称全平台通过。

[完整方法卡](../methods/A008.md)。

## A009 · 正文只呈现读者能识别的三层标题

来源：[原页](https://practicaltypography.com/headings.html)。观察：作者建议少量标题层级，让标题揭示论证而非碎片主题。

当前问题：正文主要h2/h3，实验内部另有h4/h5；若统一大小，组件内部层级会伪装成全书小节。

本轮决定（调整采用）：书级h1、章级h2、论点h3保持清晰；实验内h4/h5仍保留语义但视觉标为字段/操作组，不进入全书目录；不删除技术逻辑分组。

完成条件：读者只扫描h2/h3即可复述本章顺序；目录不挤入实验每个字段；h4/h5仍不跳过语义父层级。

[完整方法卡](../methods/A009.md)。

## A010 · 辅助信息可以安静，但不可缩成微字

来源：[原页](https://designsystem.gov.scot/styles/typography)。观察：官方限制小字用途，并给出小屏14px、大屏16px参考。

当前问题：多处diagram标签.67rem默认约10.72px；这承载技术关系，不能当无关脚注。

本轮决定（调整采用）：关键图内文字设不低于14px候选，必要时把图改为纵向或分组；真正元信息可13–14px，不通过缩字把多节点硬塞一行。

完成条件：所有箭头关系、结果状态和请求编号在100%缩放可读；393px时图文字不低于14px且不产生页面横向溢出。

[完整方法卡](../methods/A010.md)。
