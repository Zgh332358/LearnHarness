# 跨组复核与修订

原始四组候选保存在 candidate-registry.json，最终编号归一为 A001–A100。root 阅读全部100条后，对5条跨组重复或范围过宽的项目重新查看已有原页证据：

- A068：从核心内容展开改为“批量答案与单题状态一致”，根据 USWDS 独立展开状态与多项展开示例作项目推导；批量动作并不是来源原站功能声称。
- A076：从重复跳过链接改为三个阅读区域的 landmark 命名。A050 保留实际跳过导航路径。
- A081：从标题顶部留白改为手机底栏的逐项焦点遮挡验收。A049 负责导航锚点顶部定位。
- A093：从视觉顺序改为禁用作者样式后的并行图文字线性化验证。A019 保留视觉分组/DOM顺序原则。
- A100：聚焦来源链接目的地名称，稳定锚点与历史分别由 A033/A034/A039 承担。

共享前端基础的条目仍可能关联同一实现，但验收对象或设计判断不同。100条不代表100个功能或100次浏览器验证。
