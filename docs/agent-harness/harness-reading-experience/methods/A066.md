# A066 · 突出当前事件，保留其余步骤可读

类别：事件位置。决定：调整采用。

## 来源方法

[USWDS: Step indicator](https://designsystem.digital.gov/components/step-indicator/)

USWDS 当前步骤最突出，其他步骤仍应维持可读性，并显示当前数与总数。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

六事件清单目前只用加粗与下划线标记当前项；事件编号另在下方状态行。

## 主题适配与取舍

用清楚编号、短名称、细线或低饱和底色标明当前事件；保留 aria-current=step。上一/下一按钮和步骤说明分开，避免误导为所有步都可点击。

## 验收方式

能快速读出“第几事件/共六个”；当前项区别不只靠颜色；剩余步骤不是禁用按钮；不虚构已完成真实操作。
