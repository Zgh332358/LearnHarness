# A084 · 反馈被告知，正文变化不大段抢读

类别：浮层与状态。决定：调整采用。

## 来源方法

[Understanding SC 4.1.3: Status Messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)

不移动焦点的状态信息应通过角色或属性让辅助技术获知；不应把所有动态内容都做成不断播报的区域。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版实验反馈已有 polite/live 状态区，可保留；新增搜索结果数量和恢复提示需要同类处理。

## 主题适配与取舍

只让简短反馈/结果计数使用 role=status 或 polite live；大段文章和整个目录不设置 live。

## 验收方式

每次选择/提交得到明确文字反馈；需要播报的反馈区有状态语义；切章不将全章放进 aria-live。真实读屏结果需单独标明测试范围。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
