# A087 · 成功、失败、当前状态不只靠颜色

类别：颜色与视觉。决定：采纳。

## 来源方法

[Understanding SC 1.4.1: Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)

颜色不能是表达信息、动作、提示或区分元素的唯一视觉手段。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版当前目录有边线和加重，实验有反馈文字；新的强调色不能把“允许/拒绝”简化为红绿底色。

## 主题适配与取舍

状态保留文字标签；当前目录同时用位置标志与字重；错误使用文字原因，箭头标注数据/动作。

关闭颜色或查看灰度截图后，仍能辨认当前章、已选操作、允许/拒绝与正确反馈，不需要猜测色义。
