# A036 · 窄屏章末链接上下排列

类别：连续阅读布局。决定：调整采用。

## 来源方法

[Pagination | GOV.UK Design System](https://design-system.service.gov.uk/components/pagination/)

相关内容页的 block 导航建议垂直排列，并用相邻页题目提供上下文。

证据类型：官方组件说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现有 chapter-bottom 为 grid 且默认竖排，可保留其窄屏优势；新版若改成双卡片需要防止挤压长中文标题。

## 主题适配与取舍

桌面上下章可并排，窄屏自动一列；上下方向保留文字，不依赖细小箭头。整块可点击，但不扩大到覆盖相邻正文。

## 验收方式

390px 下两块顺序为上一章、下一章，标题完整、点击区域不重叠；200% 缩放时仍可导航。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
