# A009 · 正文只呈现读者能识别的三层标题

类别：标题层级。决定：调整采用。

## 来源方法

[Butterick — Headings](https://practicaltypography.com/headings.html)

作者建议少量标题层级，让标题揭示论证而非碎片主题。

证据类型：原作者教材原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

正文主要h2/h3，实验内部另有h4/h5；若统一大小，组件内部层级会伪装成全书小节。

## 主题适配与取舍

书级h1、章级h2、论点h3保持清晰；实验内h4/h5仍保留语义但视觉标为字段/操作组，不进入全书目录；不删除技术逻辑分组。

## 验收方式

读者只扫描h2/h3即可复述本章顺序；目录不挤入实验每个字段；h4/h5仍不跳过语义父层级。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
