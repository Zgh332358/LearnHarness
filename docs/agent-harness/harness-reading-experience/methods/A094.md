# A094 · 标题和操作名说明真实用途

类别：结构与语义。决定：调整采用。

## 来源方法

[Understanding SC 2.4.6: Headings and Labels](https://www.w3.org/WAI/WCAG22/Understanding/headings-and-labels.html)

已提供的标题和标签应描述主题/用途；仅有语义标签而名称含糊，仍不能帮助定位。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版每章有问题和目标，是值得保留的层次；局部表格区都叫“本节对照表”，回查时难分。

## 主题适配与取舍

保留章节问题；工具入口直接写“阅读设置/目录/查找”等用途；给宽表区具体名称，而不是全部同名。

## 验收方式

从标题和控件名称列表能判断用途；没有多余空标题、跳级造成的层级歧义或无上下文的“更多”。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
