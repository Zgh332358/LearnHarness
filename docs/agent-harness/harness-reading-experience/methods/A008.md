# A008 · 检验字体替换的视觉尺寸，而不迷信px一致

类别：字体回退。决定：调整采用。

## 来源方法

[USWDS Using type](https://designsystem.digital.gov/design-tokens/typesetting/overview/)

USWDS说明同一标称字号在不同字体上会有不同视觉大小。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前系统字体栈在Mac偏PingFang、Windows偏Microsoft YaHei；源代码字号不能证明两端读感相同。

## 主题适配与取舍

继续用本地系统字体保持独立HTML，但对中文、Harness/API英文、数字与等宽代码选实际样本；不引入只覆盖西文的品牌字体作为正文核心。

## 验收方式

检查可用Mac字体与一个明确的替代字体；标题和代码无缺字、无明显基线错位；记录未实测平台而不是宣称全平台通过。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
