# A007 · 把散落的字号汇成少量语义token

类别：字体系统。决定：调整采用。

## 来源方法

[IBM Carbon Typography](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview)

Carbon用预设字号、字重、行高组合表达角色，减少随意样式。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

HTML累计出现12、13、14、15、16、17、18、19、20、22、23、25、27、29等字号和多处rem；角色重叠。

## 主题适配与取舍

使用display/chapter/section/body/caption/ui六类语义字号；技术图另设diagram-label，禁止为每一张图追加孤立微型字号。

## 验收方式

样式表能映射七种用途；同一用途没有无理由的三种以上字号；章节、图注、按钮各保持跨页面一致。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
