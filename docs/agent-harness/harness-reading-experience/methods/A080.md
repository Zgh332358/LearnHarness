# A080 · 所有控件显示稳定的焦点环

类别：导航与键盘。决定：调整采用。

## 来源方法

[Understanding SC 2.4.7: Focus Visible](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)

可键盘操作的界面应有可见焦点指示；指示不能在获得焦点一段时间后自行消失。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版已有 focus-visible，但选择器未覆盖 input/select；深浅色卡片上焦点色需重新测算。

## 主题适配与取舍

使用 :focus-visible 统一覆盖按钮、链接、输入、选择框、summary 与程序目标；采用清楚且持续的外环。

## 验收方式

Tab 遍历每类控件，焦点位置始终可辨；无 outline:none 而无替代样式；浅深背景逐一核查。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
