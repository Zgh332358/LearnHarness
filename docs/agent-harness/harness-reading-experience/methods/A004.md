# A004 · 段落间距由样式管理，不插入空段落

类别：段落节奏。决定：采纳。

## 来源方法

[Butterick — Space between paragraphs](https://practicaltypography.com/space-between-paragraphs.html)

作者把段间距视为段首缩进的替代，并用CSS margin实现。

证据类型：原作者教材原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现有p margin为1.1em，已采用样式段距；新页面若增加容器容易产生重复间距。

## 主题适配与取舍

保留无首行缩进正文；单一prose规则管理段距，按正文、图注、提示分别设定，不添加br或空p撑版面。

## 验收方式

DOM中无装饰性空段；两个相邻普通段间距一致；图注与图体距离小于图与下一段的距离。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
