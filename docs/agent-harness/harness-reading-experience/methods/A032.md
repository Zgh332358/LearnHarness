# A032 · 章导航与小节导航拥有独立状态

类别：定位状态。决定：采纳。

## 来源方法

[Choosing the State Structure | React](https://react.dev/learn/choosing-the-state-structure)

React 指出重复、矛盾的状态容易不同步，应把相互依赖的信息从同一状态导出。

证据类型：作者说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前 currentIndex 与 IntersectionObserver 高亮各自维护；全文模式滚到后面的章节，currentIndex 不随高亮更新。

## 主题适配与取舍

统一读取当前章索引和当前小节 ID，再由它们派生位置文字、章高亮、局部目录和前后链接。实验状态保持独立，导航不重置实验。

## 验收方式

全文模式滚到第 7 章再关闭全文，仍显示第 7 章；导航高亮、章号及前后章链接均对应第 7 章；已选实验数据不丢失。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
