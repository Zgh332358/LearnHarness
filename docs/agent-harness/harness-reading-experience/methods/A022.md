# A022 · 所有机制图共享二维视觉语法

类别：图形语法。决定：调整采用。

## 来源方法

[Digital Scotland Images](https://designsystem.gov.scot/styles/images)

官方建议插图少元素、风格一致，二维矢量便于理解和缩放。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

九图分两套CSS：process-diagram与diag-figure，角半径、线条、图注大小不同，像拼接资料。

## 主题适配与取舍

统一figure、figcaption、节点和箭头token；请求/结果用明确标签，控制边可虚线并有说明；只统一视觉，不删除技术差别或加入透视。

## 验收方式

九幅图的图注、节点边角和线宽一致；未知/拒绝分支保留明确文字；移动端翻为纵向时没有把并行含义改成串行。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
