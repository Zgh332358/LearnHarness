# A059 · 本地视图切换弱于正文主线

类别：视图切换。决定：调整采用。

## 来源方法

[Carbon: Content switcher](https://www.carbondesignsystem.com/building-blocks/core/components/content-switcher/guidelines)

Carbon 视图切换用于同类内容的不同视图，允许较低强调样式。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

阅读工具把全文展开与章节切换并排；实验内未来若加“图/表”视图，容易与章节导航混在同一层。

## 主题适配与取舍

正文导航、阅读模式、实验数据选择各占清楚层级；只在相同数据有真正互补视图时采用低强调切换。拒绝把全部章节做成一排 tabs。

## 验收方式

读者能辨别是在改阅读模式还是改实验条件；同一数据切换不会清空答案；不出现18个并列标签挤压内容。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
