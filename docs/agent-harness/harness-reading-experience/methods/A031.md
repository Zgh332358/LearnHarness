# A031 · 当前位置同步文本和语义标记

类别：当前位置。决定：调整采用。

## 来源方法

[ARIA: aria-current attribute | MDN](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Attributes/aria-current)

aria-current 让辅助技术识别集合中的当前条目，page、location、step 有不同含义。

证据类型：官方参考说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现有章目录已有 aria-current=location 和绿色边线，可保留；顶部只显示“第 x / 18 节”，缺少章节主题。

## 主题适配与取舍

当前章同时更新章号、短主题及目录的 aria-current。目录中仅一个当前章；局部目录使用独立集合标记小节，避免把章导航当实验步骤。

## 验收方式

深链接、顺序跳章、全文滚动后，当前文字与高亮一致；每个导航集合最多一个 aria-current，实验自身 aria-current=step 不被改写。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
