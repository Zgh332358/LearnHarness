# A024 · 表格视觉轻量化，长解释回到段落

类别：表格与正文。决定：调整采用。

## 来源方法

[USWDS Table](https://designsystem.digital.gov/components/table/)

USWDS提供无外围框表格，并要求表格单元内容简短可扫读。

证据类型：官方设计系统指导与示例代码原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

26张表统一14px，长机制说明与短字段表混用；现有只有水平线，外观已较克制，应保留优点。

## 主题适配与取舍

维持浅表头与水平行分隔，提升阅读字号至15–16px候选；真正的对照保留表格，多个段落挤入单元格的解释转成紧邻正文；不强制全部变卡片。

## 验收方式

跨行同一列字段关系可追踪；窄屏至少保留列名或局部滚动提示；单元内没有靠缩字容纳多段论述。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
