# A018 · 单列阅读可以配目录，但不要把正文变多栏

类别：内容栏结构。决定：采纳。

## 来源方法

[ONS Accessible text formatting](https://service-manual.ons.gov.uk/brand-guidelines/typography/accessible-text-formatting)

ONS建议以单列正文为默认，多列场景需要明确阅读顺序。

证据类型：官方设计指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前左侧目录＋单列正文符合方向；增加右侧技术说明栏会压缩中文行宽并分散注意。

## 主题适配与取舍

桌面允许目录侧栏，主叙述保持一列；注释和实验解释紧跟对应内容，不另开常驻第三栏；手机目录折叠后正文全宽。

## 验收方式

从标题、段落、图、反馈能按DOM顺序读完；200%缩放不出现三列正文；重要解释不会仅在侧栏存在。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
