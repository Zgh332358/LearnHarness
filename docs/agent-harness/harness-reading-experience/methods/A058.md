# A058 · 勾选记录与已组装预览明确分开

类别：草稿状态。决定：调整采用。

## 来源方法

[USWDS: Checkbox](https://designsystem.digital.gov/components/checkbox/)

USWDS 复选框用于独立多选，文字标签须清楚表达选中和未选中含义。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

上下文实验选择改变后不会自动改预览，这是教学关键；但“选择已修改，尚未组装”的视觉位置容易被长输入块分隔。

## 主题适配与取舍

保留多选与显式组装按钮，在预览标题旁显示短状态“选择已改变·预览未更新”；正常组装后恢复“已组装·未发送”。

## 验收方式

取消目标记录后预览仍不变，且旁边立即有待组装提示；按组装后才更新文本；未选资料仍被解释为外部保存。
