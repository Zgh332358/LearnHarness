# A093 · 去掉视觉排版后仍能读出并行与归属

类别：线性化验证。决定：采纳。

## 来源方法

[Understanding SC 1.3.2: Meaningful Sequence](https://www.w3.org/WAI/WCAG22/Understanding/meaningful-sequence.html)

内容顺序影响意义时，正确序列应可被程序确定；CSS 视觉位置不能改变关键因果顺序。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

并行图在手机上按视觉纵排；若读者只读DOM文字或忽略样式，纵向文本可能被当成串行动作。

## 主题适配与取舍

保留DOM中并行说明与每组职责标题；关掉样式观察文字顺序，确认节点与所在Agent/工具组相邻，图注仍说明竖排不代表串行。

## 验收方式

禁用作者样式后，工具并行与子Agent循环两组名称和边界仍存在，读序不需依赖CSS位置或颜色。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
