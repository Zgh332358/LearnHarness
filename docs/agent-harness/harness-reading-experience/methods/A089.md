# A089 · 320 CSS px 时正文只需竖向阅读

类别：缩放与响应。决定：调整采用。

## 来源方法

[Understanding SC 1.4.10: Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)

竖向内容应在等效 320 CSS px 宽度重排，避免双向滚动；真正二维数据表等可局部滚动。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版已有单栏断点和局部宽表容器，但整体 320px、图节点和较长工具栏需重新核查。

## 主题适配与取舍

正文和实验在窄屏堆叠；复杂表格只在有名称的局部容器横滚；长英文/ID 可折行。

## 验收方式

320px 下 document.scrollWidth 不超过 clientWidth；正文无横滚；允许横滚的表格局部边界不溢出页面且键盘可达。另在桌面 400% 放大核查。
