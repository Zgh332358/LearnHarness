# A100 · 来源链接的名称说明目的地内容

类别：链接文本。决定：调整采用。

## 来源方法

[Understanding SC 2.4.4: Link Purpose (In Context)](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html)

链接用途可由文字或程序可确定的上下文理解；名称与到达页主题相呼应能帮助连续阅读。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

正文引用资料数量多，新的搜索与导航若加“这里/查看”等重复词，会让读者难判断外部资料与书内位置。

## 主题适配与取舍

正文来源继续用作者或资料内容命名；书内导航带章题，检索结果带章名与原文片段；不改为裸URL、连续“点击这里”或纯图标。

## 验收方式

抽查正文一手资料链接及搜索结果，脱离周围长段仍可判断将到哪类资料；相同目的地名称不制造不同事实含义。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
