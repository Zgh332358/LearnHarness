# A016 · 用距离表达“是一组”，减少阅读猜测

类别：组件内外间距。决定：调整采用。

## 来源方法

[IBM Carbon Spacing](https://www.carbondesignsystem.com/building-blocks/foundations/spacing/overview)

Carbon以近距离表达关联、较远距离表达独立，并提供间距刻度。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

图与图注、实验输入与反馈、章标题与目标卡分别有多个独立margin值，视觉分组可能不统一。

## 主题适配与取舍

采用4/8/12/16/24/32/48px候选刻度；图注到图体16、图表内字段8–12、教学模块外32–40；文字组距离小于跨模块距离。

## 验收方式

每张图的标题、图体、说明被看成同一组；操作按钮与其反馈无其他模块夹入；模块之间有明确休息空间。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
