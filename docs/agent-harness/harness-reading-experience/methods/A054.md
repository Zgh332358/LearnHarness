# A054 · 禁用状态同时交代前置条件

类别：禁用反馈。决定：调整采用。

## 来源方法

[Carbon: Button](https://www.carbondesignsystem.com/building-blocks/core/components/button/guidelines)

Carbon 按钮包含交互状态；文字溢出时推荐换行而非截断。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前禁用按钮仅 opacity .45；回执实验的判断按钮须先选答案，读者可能只看到灰按钮。

## 主题适配与取舍

保持原生 disabled，并在紧邻状态行提示“先选择下一步”；首尾事件交代“已到首事件/末事件”。禁用不靠颜色独立传达。

## 验收方式

每个不可操作状态有可见原因；长文案能换行；禁用按钮不可触发动作；仍能回到有效选择。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
