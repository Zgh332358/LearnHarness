# A034 · 从任意小节入口恢复完整阅读上下文

类别：深链接与上下文。决定：采纳。

## 来源方法

[Search | VitePress](https://vitepress.dev/reference/default-theme-search)

本地搜索文档 ID 可以包含 page.html#section，结果直接定位具体小节。

证据类型：作者说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前 showChapter 会根据 hash 找所属章节，已支持深链接；新增局部目录和搜索必须复用这条有效逻辑。

## 主题适配与取舍

所有内部跳转共用一条导航函数：先识别所属章，再显示章、更新目录，最后定位小节；不让隐藏章节中的搜索命中只改变 hash 而无正文。

## 验收方式

直接打开第 7 章小节 hash、从第 1 章点击搜索结果、浏览器前进都能显示第 7 章；页面只读模式和全文模式均正确。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
