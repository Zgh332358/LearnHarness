# A063 · 即时教学计算不加入假等待动画

类别：等待真实性。决定：舍弃。

## 来源方法

[Carbon: Inline loading](https://www.carbondesignsystem.com/building-blocks/core/components/inline-loading/guidelines)

Carbon 将 inline loading 用于不能立即完成的动作。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

四个实验全部由本地预设数据同步更新，不存在网络或真实执行等待。

## 主题适配与取舍

拒绝为显得像 Agent 运行加入假旋转、假进度或人为延时。解释现实等待时展示可回看的记录状态，并写明是教学模拟。

## 验收方式

实验动作立即响应；没有计时后自动假装已查询/已预订；停顿动画不会被误解为现实服务正在运行。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
