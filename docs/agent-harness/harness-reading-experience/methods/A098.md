# A098 · 打印包含全文和可读的静态实验

类别：性能与交付。决定：调整采用。

## 来源方法

[MDN Printing](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries/Printing)

print 媒体样式可调整纸面排版，beforeprint/afterprint 可处理打印前后的界面状态。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版已有显示隐藏章、展开答案和静态表的代码；此前证据为静态检查，本轮应实际打印介质观察。

## 主题适配与取舍

打印隐藏工具栏/固定按钮，展示所有章节与静态步骤；深底色改为纸面可读样式，长代码折行；退出打印恢复原阅读状态。

## 验收方式

实际 print 介质或打印预览中 18 节全部显示；没有固定栏覆盖；图表/长代码无截断；关闭预览后当前章、展开状态恢复。
