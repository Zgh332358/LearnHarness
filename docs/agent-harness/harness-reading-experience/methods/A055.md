# A055 · 四个对照条件让读者直接看到

类别：选项发现。决定：调整采用。

## 来源方法

[USWDS: Select](https://designsystem.digital.gov/components/select/)

USWDS 将少量选项优先匹配单选，并要求 select 保留明确标签。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

检查与恢复实验都只有四个情境，却把其余三个藏在 select 里。

## 主题适配与取舍

优先试四项竖排单选或可见情境列表；若竖排造成过长，则保留原生 select 并在上方展示四类问题的简短列表。切换只改变本地展示。

## 验收方式

首次进入不用打开下拉就知道有哪些对照；320–390px 下能完整读选项；切换不产生真实调用或自动判断。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
