# A029 · 局部目录只收录有用的标题层级

类别：信息层级。决定：调整采用。

## 来源方法

[Default Theme Config | VitePress](https://vitepress.dev/reference/default-theme-config)

outline 可限定标题级别，也可单独设置标签，深目录不是唯一默认。

证据类型：作者说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前 HTML 有章节 h2、小节与实验 h3；若把实验内卡片再加入目录会增加噪声。

## 主题适配与取舍

当前章目录仅从 h3 构建，含教学实验标题；卡片字段、图内节点、按钮不作为导航标题。保留 h2 作为章题而非局部列表首个重复项。

## 验收方式

本章目录数量等于当前章 h3 数量；目录没有“负责人”“输入”等图内标签；标题顺序与正文相同。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
