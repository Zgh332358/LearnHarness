# A064 · 状态变化保持锚点和布局稳定

类别：等待布局。决定：调整采用。

## 来源方法

[Carbon: Inline loading](https://www.carbondesignsystem.com/building-blocks/core/components/inline-loading/guidelines)

Carbon 要求临时加载反馈沿用原内容的位置和对齐。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

事件切换时阶段输入和输出长度不同；重设计若让状态横幅出入，会推动按钮与主观察区域跳动。

## 主题适配与取舍

将事件编号、负责者、动作按钮设为稳定观察位置；文本区自然扩展，不用固定高度裁掉内容。已有 aria-live 简短通知保持原位。

## 验收方式

相邻事件切换后按钮不随机换位；页面不主动滚回顶部；文本完整可读；状态更新不会夺走键盘焦点。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
