# A096 · 展开/收起有原生语义和明确状态

类别：结构与语义。决定：调整采用。

## 来源方法

[APG Disclosure (Show/Hide) Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)

Disclosure 包含控制器和显示/隐藏内容；按钮模式使用 Enter/Space，并暴露展开状态。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版目录、静态实验表、自测已用 details；新的阅读设置宜延续此模式，避免堆入自制点击 div。

## 主题适配与取舍

常用轻量展开用 details/summary；自定义按钮才同步 aria-expanded/controls，避免为原生 summary 写重复且冲突的状态。

## 验收方式

每个展开器 Enter/Space 可切换；关状态不留下可 Tab 到的隐藏操作；打开的内容可读，名称明确。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
