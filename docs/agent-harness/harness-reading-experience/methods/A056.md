# A056 · 判断题的答案选项不预设正确项

类别：判断选择。决定：采纳。

## 来源方法

[USWDS: Radio buttons](https://designsystem.digital.gov/components/radio-buttons/)

USWDS 单选文档提醒默认值可能偏置判断，并规定 fieldset 与 legend 分组。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

恢复实验已使用 radio 与 legend，初始化没有默认答案；此正确机制应在美化时保留。

## 主题适配与取舍

不把某个答案预先勾选，不按正确性先染绿；四项采用一致文字样式，回答后再解释。

## 验收方式

初始 radio 均未选择；正确项位置不固定；只选中答案不会提前出现判断结果；legend 能说明选择的问题。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
