# A070 · 表格用于比较，列和单位一致

类别：表格语法。决定：调整采用。

## 来源方法

[USWDS: Table](https://designsystem.digital.gov/components/table/)

USWDS 推荐短表头、统一列格式，表格样式保持简单。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

正文表格已有轻表头与横线；数字、日期、状态文字未形成跨表一致规则，部分宽格容纳长段落。

## 主题适配与取舍

只把同字段对照留在表格；中文说明左对齐，金额/可求和数值右对齐且明确单位，日期按同一格式。多段解释移到表格邻近正文。

## 验收方式

同一列没有混用人均与总价；表头能单独解释列含义；不添加无关排序筛选；长段落不压成密密麻麻的单元格。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
