# A027 · 导航短名称与完整章题分工

类别：目录排版。决定：调整采用。

## 来源方法

[Sidebar items | Docusaurus](https://docusaurus.io/docs/sidebar/items)

文档条目可使用独立的侧栏 label，不要求照搬文档标题。

证据类型：作者说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

目录宽 244px，却重复 20–30 字左右完整章题，扫描成本高。

## 主题适配与取舍

目录使用保留核心名词的短名称，例如“02 输入与模型输出”；进入章节后显示完整题目。可访问名称仍能指明章号与主题，不能只保留数字。

## 验收方式

所有短名称与原章意一致；在 1280px 和 390px 下可辨识；没有省略号截掉区分所需词语。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
