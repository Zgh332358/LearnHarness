# A075 · 交互先让读者看见输入与输出

类别：教学观察。决定：采纳。

## 来源方法

[Red Blob Games: Introduction to the A* Algorithm](https://www.redblobgames.com/pathfinding/a-star/introduction.html)

Red Blob 先解释输入图与输出路径，再将算法分解为可逐步观察的过程。

证据类型：author-tutorial-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

六事件实验已有负责者、阶段输入、阶段输出；新布局若只强调动画或角色图，会丢失可核对的数据。

## 主题适配与取舍

将输入、输出、执行责任保持为每次观察的固定槽位，重复用同一餐厅案例。每次变化围绕当前一个问题，不加入自由拖拽或无明确意义的参数。

## 验收方式

每步能回答谁收到什么、谁产生什么；Q01/Q02 与返回记录保持配对；模型提出请求不会提前染成真实执行完成；无交互时仍有静态对照。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
