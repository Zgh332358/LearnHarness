# A099 · JavaScript 失效时仍能读完教材

类别：性能与交付。决定：采纳。

## 来源方法

[GOV.UK: Building a robust frontend using progressive enhancement](https://www.gov.uk/service-manual/technology/using-progressive-enhancement)

渐进增强从 HTML/CSS 可用的核心开始，JavaScript 提供增强；无需复杂界面的页面不必为了框架而引入框架。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版所有章初始在 HTML 中，交互有静态详情和 noscript；新增设置或导航若默认隐藏正文会破坏这项基础。

## 主题适配与取舍

无 JS 时正文和目录仍可用；实验保留静态步骤/对照表，隐藏不可用动作并解释；JS 成功初始化后才启用分页增强。

## 验收方式

禁用脚本重新载入，不是只删 script 后猜测：18 节可读、目录锚点有效、四个实验有静态说明；不显示无效空按钮。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
