# A047 · 轻量本地搜索补上回查能力

类别：文档搜索。决定：调整采用。

## 来源方法

[Search | VitePress](https://vitepress.dev/reference/default-theme-search)

VitePress 支持浏览器内索引的本地全文搜索，不必依赖在线服务。

证据类型：作者说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前 3.3 万字中没有 input[type=search]，只能记住章节或依赖浏览器查找；章隐藏会影响常规回查。

## 主题适配与取舍

在目录上方提供单个本地搜索输入，优先搜索章题和 h3 小节；结果显示所属章及标题，后续才扩展正文短片段。索引在页面本地，不加入 AI 问答或外部 API。

## 验收方式

离线打开文件，搜索“幂等”“上下文”“MCP”均有正确目标；清空恢复正常目录；没有结果时明确显示无结果并保留输入。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
