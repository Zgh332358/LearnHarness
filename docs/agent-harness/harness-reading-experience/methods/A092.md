# A092 · 减少运动偏好下没有装饰性位移

类别：偏好与退化。决定：调整采用。

## 来源方法

[MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

prefers-reduced-motion: reduce 能识别设备上用户减少运动的选择，从而调整动画。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版已使用 auto 滚动，reduce 分支仅重复该设置；新的面板动画或主题过渡不能遗漏。

## 主题适配与取舍

默认避免持续动画；在 reduce 下取消平滑滚动、位置移动和非必要过渡；实验依然使用明确单步。

## 验收方式

模拟 reduce，CSS/运行结果中无非必要动画和平滑滚动；操作状态变化仍明确；不使用自动播放 3D 或跟随滚动的装饰视差。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
