# A025 · 列表只在顺序或同类比较时强化视觉

类别：列表形式。决定：调整采用。

## 来源方法

[Digital Scotland Typography](https://designsystem.gov.scot/styles/typography)

官方仅在序列或数量有意义时用编号，否则用项目列表。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

## 主题适配与取舍

真正运行事件保留编号并与Q01等请求编号分开；独立条件用项目列表；因果说明保持段落，不为扫读把每句拆成序号卡片。

## 验收方式

并行分支不被顺序编号伪装为串行；列表引导语明确；编号的意义可以用一句话说明，正文仍有连接推理。
