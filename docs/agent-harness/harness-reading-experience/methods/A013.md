# A013 · 中英混排间距处理语义边界，代码保持原样

类别：中西文混排。决定：调整采用。

## 来源方法

[W3C 中文排版需求（工作草案）](https://www.w3.org/TR/clreq/)

草案指出汉字与西文间可有小间距，标点邻接有例外。

证据类型：W3C工作草案内容核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现文不少技术词已手工留空格；全局letter-spacing或替换字符串会波及JSON、URL及编号。

## 主题适配与取舍

保持文稿已有语义空格；若浏览器支持text-autospace可局部渐进增强；不对pre/code和href进行空格注入，视觉调节先看混排样本。

## 验收方式

API、Harness、Q01等正文术语不挤连；复制JSON仍合法、URL仍可用；引号括号与词语之间无夸张空隙。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
