# A078 · 局部滚动区可以进入，也可以离开

类别：导航与键盘。决定：采纳。

## 来源方法

[Understanding SC 2.1.2: No Keyboard Trap](https://www.w3.org/WAI/WCAG22/Understanding/no-keyboard-trap.html)

键盘进入组件后应能用键盘离开；若退出方式超出通常约定，应告知用户。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版横滚表格已有 tabindex=0，但新增目录、搜索或浮层可能制造焦点困住的情况。

## 主题适配与取舍

表格横滚区使用自然 Tab 顺序，方向键可滚；非模态目录不要人为循环拦截焦点。

## 验收方式

对目录、宽表、代码区与四个实验逐一 Tab 进入并离开，Shift+Tab 可反向离开，无死循环。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
