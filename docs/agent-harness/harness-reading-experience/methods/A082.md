# A082 · 阅读设置优先行内展开，减少模态负担

类别：浮层与状态。决定：舍弃。

## 来源方法

[APG Dialog (Modal) Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)

真正模态对话框需要焦点进入内部、Tab 留在内部、Escape 关闭、关闭后回到触发处，并使背景不可操作。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版没有 dialog，字号/目录等轻操作无须增加遮住全文的弹窗。

## 主题适配与取舍

拒绝把普通阅读设置设计成自制模态；优先原生 details 行内展开。若后来采用真模态，按完整对话框约定验收。

## 验收方式

阅读设置和目录可在当前上下文中打开关闭，不因视觉弹层丢失焦点；如存在模态，额外测试 Escape、回焦点和背景不可操作。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
