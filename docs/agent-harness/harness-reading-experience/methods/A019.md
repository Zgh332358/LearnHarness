# A019 · 视觉顺序与实际阅读顺序保持一致

类别：信息顺序。决定：采纳。

## 来源方法

[ONS Accessible text formatting](https://service-manual.ons.gov.uk/brand-guidelines/typography/accessible-text-formatting)

ONS要求阅读顺序匹配视觉层级，并用空间、尺度、对比排序。

证据类型：官方设计指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现有学习问题、章节purpose、正文和实验顺序合理；美化时CSS order或网格重排可能让图跑到正文前。

## 主题适配与取舍

维持问题→解释→图→操作→结果说明；桌面并排只针对同时比较的输入/结果，手机按原始DOM顺序堆叠；不用CSS order造不同故事。

## 验收方式

屏幕阅读与Tab顺序等于视觉顺序；窄屏上下次序仍保留输入先于结果；关闭CSS仍能读到完整论证链。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
