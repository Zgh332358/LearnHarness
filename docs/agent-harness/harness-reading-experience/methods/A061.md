# A061 · 短状态与长教学依据分层

类别：反馈层级。决定：调整采用。

## 来源方法

[Carbon: Notification](https://www.carbondesignsystem.com/building-blocks/core/components/notification/guidelines)

Carbon 将简短状态通知与上下文信息区分，并强调靠近关联内容。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前 .lab-feedback 与 .lab-status 用同样软色块，长解释和“一共几条”短状态看起来同类。

## 主题适配与取舍

短状态用轻文字行与小标记，长依据用正文段落和清楚小标题；教学解释不受通知两行限制，避免缩字号塞入窄条。

## 验收方式

一眼能找到“目前显示/是否已组装”；仍能完整阅读原因和不能推断之处；状态、答案、教学说明不重复整段文字。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
