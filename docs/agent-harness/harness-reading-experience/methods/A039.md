# A039 · 浏览器后退回到原段落

类别：阅读连续性。决定：调整采用。

## 来源方法

[History: scrollRestoration property | MDN](https://developer.mozilla.org/en-US/docs/Web/API/History/scrollRestoration)

History 提供 auto/manual 两种历史滚动恢复行为；auto 恢复先前滚动位置。

证据类型：官方 API 说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前所有 hashchange 都调用 scrollIntoView，回到同一个章节可能被强制定位到标题，覆盖浏览器恢复行为。

## 主题适配与取舍

把主动导航与历史恢复区别处理。优先保留浏览器滚动恢复；若自管历史，则保存已存在条目的阅读锚点与偏移，不能只保存章号。

## 验收方式

在第 2 章中段跳到第 8 章，再按后退，应回到第 2 章原段落附近；前进回到第 8 章；没有额外空白历史条目。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
