# A046 · 拒绝目录与内容中的嵌套折叠

类别：导航复杂度。决定：舍弃。

## 来源方法

[Accordion | GOV.UK Design System](https://design-system.service.gov.uk/components/accordion/)

官方建议避免手风琴嵌套；折叠、标签、details 彼此嵌套会增加查找困难。

证据类型：官方组件说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

目录已有一层 details，正文已有答案和实验记录；再将每个目录组和每章都做折叠，会形成连续寻找。

## 主题适配与取舍

桌面目录组只用标题，不嵌套 details；窄屏只由一个“章节目录”入口控制整体。内容保留单层补充展开，实验内不再做二级手风琴。

## 验收方式

任一章节从打开目录到选择章节最多一次展开；DOM 中没有 details 内的 details；核心内容不会被多层折叠隐藏。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
