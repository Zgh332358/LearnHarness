# A001 · 先确定正文阅读字号，再缩放标题

类别：阅读字级。决定：调整采用。

## 来源方法

[Digital Scotland Typography](https://designsystem.gov.scot/styles/typography)

官方分别列出大小屏字级，正文和辅助文字有独立角色。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

正文为17px，窄屏16px；它是可用起点，但视觉修改应先锁定正文再调封面。

## 主题适配与取舍

正文采用桌面18px、窄屏17px作为首轮候选，用rem表达并允许浏览器放大；标题依据中文换行另行微调，不直接搬Roboto数值。

## 验收方式

默认与200%缩放下正文不裁切；同一章节的正文、段首和段尾字号一致；至少检查一个长段与一段中英混排。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
