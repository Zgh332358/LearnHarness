# A068 · 批量答案与单题展开状态保持一致

类别：披露状态一致性。决定：采纳。

## 来源方法

[USWDS: Accordion](https://designsystem.digital.gov/components/accordion/)

USWDS 展示各项独立的 aria-expanded 状态，并提供允许多项展开的示例。批量开关是本项目的扩展推导。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现有十道自测可逐题展开，全部答案按钮却只以自身旧状态决定下一动作；单题变化后标签可能不对应当前集合。

## 主题适配与取舍

保留各题原生 details。全部答案按钮从十题是否全部打开计算文案与 aria-expanded；监听单题 toggle，允许独立思考与统一回查。

## 验收方式

批量打开后手动关闭一题，按钮应变为“显示全部答案”；再次点击打开十题，批量收起恢复全部关闭。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
