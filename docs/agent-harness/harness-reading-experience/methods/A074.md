# A074 · 图解使用有限且一致的视觉编码

类别：图解编码。决定：调整采用。

## 来源方法

[USWDS: Data visualizations](https://designsystem.digital.gov/components/data-visualizations/)

USWDS 建议围绕一个中心意思、克制颜色，并提供文字说明和非颜色区分。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

多数 diag-node 都以 currentColor 实线框显示，边界虚线含义未统一；小字号的箭头标签较难扫读。

## 主题适配与取舍

规定角色、数据、边界的少量视觉语法：角色有名称，流向有动词，范围以明确虚线/标题表示；颜色只辅助输入、执行、结果区分。每图保留问题与可读结论。

## 验收方式

去掉颜色也可追踪流向；同种边框不跨图变义；箭头标签窄屏至少正常可读；图不靠悬停才能获取关键因果。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
