# A021 · 正文链接使用可认出的下划线

类别：链接外观。决定：采纳。

## 来源方法

[Digital Scotland Typography](https://designsystem.gov.scot/styles/typography)

官方正文链接默认带下划线，句末标点放在链接外。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

正文链接已有下划线与underline-offset4px，目录和导航链接无下划线，角色合理。

## 主题适配与取舍

保留正文来源链接下划线；目录/章节导航可免下划线但需选中底色和焦点轮廓；避免来源小字淡化到看不出可点击。

## 验收方式

正文中链接与普通彩色字能区分；下划线不压住中文下沿；键盘焦点明确；来源标题独立可理解。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
