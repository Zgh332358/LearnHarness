# A011 · 保留网页左对齐，拒绝整书两端对齐

类别：中文段落对齐。决定：舍弃。

## 来源方法

[W3C 中文排版需求（工作草案）](https://www.w3.org/TR/clreq/)

草案描述中文书籍常采用两端对齐，且需配套字距和标点调整。

证据类型：W3C工作草案内容核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前正文默认左对齐；内容有Harness、MCP、API和链接，窄屏若简单justify容易出现离散空隙。

## 主题适配与取舍

拒绝把中文纸书的两端对齐直接移到本教材；正文和图中叙述左对齐，短节点标签可居中；后续只有经过浏览器中英混排验证才考虑局部justify。

## 验收方式

长中文与中英混排均没有为对齐形成的大空洞；移动端正文每行起点稳定；左右留白自然，不手插空格对齐。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
