# A012 · 保护中文标点的行首行尾关系

类别：中文换行。决定：采纳。

## 来源方法

[W3C 中文排版需求（工作草案）](https://www.w3.org/TR/clreq/)

草案区分禁则强度，说明结束标点不应独立出现在行首。

证据类型：W3C工作草案内容核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

全局未设中文line-break规则；code用了overflow-wrap:anywhere，图的祖先也有anywhere。

## 主题适配与取舍

中文叙述采用word-break:normal与line-break:strict作为渐进增强；只给URL、代码和长标识局部overflow-wrap:anywhere，避免无区别打断自然语言。

## 验收方式

393px下测试含括号、引号、省略号段落；检查常用句号/逗号没有被自定义强制换行孤立；长call_id仍不会挤出容器。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
