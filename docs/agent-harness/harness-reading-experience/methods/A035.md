# A035 · 上下章链接说明将读到什么

类别：连续阅读。决定：调整采用。

## 来源方法

[Prev Next Links | VitePress](https://vitepress.dev/reference/default-theme-prev-next-links)

章末前后链接可独立定制文字和目标，而不必仅显示方向按钮。

证据类型：作者说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现有章末已有带完整标题的前后链接，是有效设计；顶部“上一节/下一节”不显示目标。

## 主题适配与取舍

章末保留描述性前后链接，压缩成两张轻量导航块：方向小标签 + 短主题；顶部工具如保留，则有目标主题的可访问名称或辅助文字。

## 验收方式

第 4 章下一章指向“失败与执行边界”；首章没有虚假上一章，末附录没有虚假下一章；方向文字与链接目标一致。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
