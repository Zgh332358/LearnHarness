# A045 · 补充展开标签先说明会看到什么

类别：渐进展示标签。决定：调整采用。

## 来源方法

[Details | GOV.UK Design System](https://design-system.service.gov.uk/components/details/)

details 适合少数用户才需要的补充信息，summary 应简短描述内容。

证据类型：官方组件说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

实验中的静态记录和自测答案已有 details；若 summary 只写“展开”则无法预判内容。

## 主题适配与取舍

使用“查看六个事件的完整记录”“查看判断依据”等内容型标签；打开后用“收起完整记录”或原标签表达状态，保持原生键盘操作。

## 验收方式

所有补充 summary 能独立说明内容；Enter/Space 可展开和收起；必需正文不被挪入 details。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
