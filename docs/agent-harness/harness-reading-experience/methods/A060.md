# A060 · 解释反馈留在刚操作的位置

类别：反馈位置。决定：采纳。

## 来源方法

[Carbon: Notification](https://www.carbondesignsystem.com/building-blocks/core/components/notification/guidelines)

Carbon inline 反馈靠近相关对象，并持续到用户处理或消除该状态。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

实验已有下方 .lab-feedback；读者需要反复比较，不能在重设计时换成消失的 toast。

## 主题适配与取舍

判断结果与依据留在按钮附近，使用稳定的反馈区。正确、需核对、未知用文字和低强度边界说明，不弹 modal、不自动消失。

## 验收方式

判断后可随时重读依据；反馈不会覆盖题目；切换情境清理旧反馈，避免将上题结论带到新题。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
