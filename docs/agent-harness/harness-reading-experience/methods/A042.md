# A042 · 每章开头保留可核查的学习问题

类别：章首引导。决定：采纳。

## 来源方法

[Quick Start | React](https://react.dev/learn)

React Learn 在正文前列出本页将覆盖的学习点，再进入示例。

证据类型：网页结构观察（文本提取）。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前每章已有本章问题与“读完应能”，比单独章题更有助于理解，应作为新版层次中心保留。

## 主题适配与取舍

章首结构固定为章号/题目、一个核心问题、一句可观察目标，然后正文；用字重和间距区分，不再叠放同义摘要或装饰性副标题。

## 验收方式

15 个正文章都有问题与目标；目标能指向判断、追踪或比较动作；手机首屏能读到核心问题而非被导航卡片占满。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
