# A073 · 复制只服务于真正可复用的内容

类别：复制范围。决定：舍弃。

## 来源方法

[Carbon: Code snippet](https://www.carbondesignsystem.com/building-blocks/core/components/code-snippet/guidelines)

Carbon 复制功能为可选，需成功确认；内容必须保持可复制的正确形式。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现有示例多为概念教学数据，没有复制按钮；默认增加全页复制会增加操作噪声。

## 主题适配与取舍

本轮不统一添加每段复制按钮。仅在后续出现可复用检查清单或模板时增设明确“复制模板”；成功提示以实际复制结果为准，失败保留手选文本。

## 验收方式

正文不因复制按钮增密；不存在示例可直接执行的暗示；若实现复制，内容与看到的文本一致，失败不显示已复制。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
