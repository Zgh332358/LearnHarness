# A048 · 搜索结果以标题优先，保持可辨认上下文

类别：搜索结果展示。决定：调整采用。

## 来源方法

[Search | VitePress](https://vitepress.dev/reference/default-theme-search)

本地搜索配置示例对标题赋予更高权重，也提供结果详情与无结果的本地化文字。

证据类型：作者说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

新增搜索若只给任意命中段落，非技术读者会收到许多没有章节背景的碎片。

## 主题适配与取舍

结果先按章题/小节题命中排序，显示“章号 · 章名 / 小节名”；若搜正文，每项只带一个短上下文片段，限制首屏结果数，不生成脱离原文的答案。

## 验收方式

同一关键词命中标题和正文时，标题结果优先；点击结果到具体小节；一条结果不重复章题三次，不把实验反馈的多段长文塞满列表。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
