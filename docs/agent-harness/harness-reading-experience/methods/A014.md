# A014 · 正文用中性深色，强调色留给动作与重点

类别：正文颜色。决定：调整采用。

## 来源方法

[IBM Carbon Typography](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview)

Carbon要求连续文字保持中性，把彩色用于行动及特定状态。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

整书ink为偏绿#24352c；图线多次currentColor，因此正文和图边都带绿，缺少角色差异。

## 主题适配与取舍

正文换近中性的暖灰黑；森林绿仅用于链接、选中目录、关键Harness区域和主按钮；图边界用中性灰，不将每段术语全部染绿。

## 验收方式

去除色彩仍能靠字号和标签分辨结构；正文不出现无用途的彩色句；强调色使用清单和语义一致。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
