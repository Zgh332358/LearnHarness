# A088 · 文字放大两倍仍能读和操作

类别：缩放与响应。决定：调整采用。

## 来源方法

[Understanding SC 1.4.4: Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)

文本应可放大至 200% 而不丢失内容和功能；控件标签也属于需考虑的文本。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版字体多用 px，未禁止浏览器缩放，但放大后的控件、图注和目录没有本轮实测证据。

## 主题适配与取舍

改为相对字号和可伸缩容器；保留浏览器缩放；阅读字号设置可以辅助，不能代替浏览器放大验收。

## 验收方式

100%、125%、150%、200% 浏览器放大中，正文、图注、操作标签没有截断/重叠，所有阅读与实验功能可达。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
