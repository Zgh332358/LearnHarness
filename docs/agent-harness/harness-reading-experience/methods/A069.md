# A069 · 披露标题的触发范围与状态可预测

类别：披露触达。决定：调整采用。

## 来源方法

[USWDS: Accordion](https://designsystem.digital.gov/components/accordion/)

USWDS 推荐整个披露标题可选，并为内部控件留出间距。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

details summary 使用原生标记，但样式只指定文字，不统一 hover/focus、打开后的标题位置。

## 主题适配与取舍

保持原生 details/summary，把标题行做完整可操作区；箭头与展开状态一致，展开后标题不消失。内部复制或其他动作与标题留足间隔。

## 验收方式

键盘 Enter/Space 可展开；点击标题文字和标记都有效；展开不会触发内部动作；关闭后仍能定位原问题。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
