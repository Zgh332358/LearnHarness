# A005 · 让标题更靠近它引出的内容

类别：标题邻接。决定：采纳。

## 来源方法

[USWDS Typography](https://designsystem.digital.gov/components/typography/)

官方要求标题上方空间大于下方，使它关联后面的正文。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

h3上2em下.7em已有方向；实验标题与外层h3共用规则又被覆盖，可能破坏一致性。

## 主题适配与取舍

为正文h3与实验内部标题分别命名样式；正文标题前距约2.25rem、后距.8rem，组件标题前距更小，不把同一数值强制到所有层级。

## 验收方式

普通h3到首段间距小于h3与上一段的间距；实验内部h3不产生巨大空白；各章节规则相同。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
