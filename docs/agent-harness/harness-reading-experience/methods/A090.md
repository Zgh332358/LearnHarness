# A090 · 用户调整文字间距不损坏布局

类别：缩放与响应。决定：调整采用。

## 来源方法

[Understanding SC 1.4.12: Text Spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)

用户覆盖行距 1.5、段后距 2、字距 .12、词距 .16 倍字号时，不应丢信息或功能；语言特性有适用范围。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版正文行距已为 1.9，但这不等于用户覆盖间距后的控件与图形已经通过。

## 主题适配与取舍

避免固定文本高度和省略必需文案；中文主要核查行/段/字间距，混排英文同时观察词距。

## 验收方式

注入指定间距覆盖样式，在首页、图最密章和四个实验核查：不出现文本裁切、重叠或按钮失去名称；不能仅以原始 line-height 宣称通过。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
