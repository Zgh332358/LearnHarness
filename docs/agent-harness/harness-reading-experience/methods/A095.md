# A095 · 表格承担比较，并保留列行含义

类别：结构与语义。决定：调整采用。

## 来源方法

[GOV.UK Design System: Table](https://design-system.service.gov.uk/components/table/)

GOV.UK 用表格帮助行列比较，使用 caption 描述主题、th/scope 表明行列含义；表格不用于页面布局。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版 26 张表仅 3 个 caption；93 个 th 中只有 12 个 scope。二维比较很好，但辅助技术理解线索不齐。

## 主题适配与取舍

保留真正比较表；补具体 caption（可视觉隐藏）、列头 scope=col，明确作行头的单元格用 scope=row；不把所有表改成丢列关系的卡片。

## 验收方式

26 张现存表均有可确定的主题；全部列头范围明确；窄屏查看任意数据时可追溯所属列；宽表只局部滚动。
