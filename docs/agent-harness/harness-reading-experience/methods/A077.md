# A077 · 每个阅读与实验操作均可键盘完成

类别：导航与键盘。决定：采纳。

## 来源方法

[Understanding SC 2.1.1: Keyboard](https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html)

功能应可通过键盘完成且不要求特定敲击时序；原生链接、按钮和表单能降低自定义按键负担。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版多数控件为原生 HTML，是可保留的基础；本轮新增阅读设置和导航也必须一起验收。

## 主题适配与取舍

保留 button/select/input/details；链接用于前往位置，按钮用于动作；不用仅 hover 可见的必要操作。

## 验收方式

只用 Tab、Shift+Tab、Enter、Space 和原生选择键，完成章节导航、全文切换、四个实验与答案展开。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
