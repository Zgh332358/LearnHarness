# A015 · 用角色色板，不为每个图或章任意加颜色

类别：颜色语义。决定：调整采用。

## 来源方法

[USWDS Using color](https://designsystem.digital.gov/design-tokens/color/overview/)

官方把完整色库与项目角色色区分，项目只使用少数色族。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

已有paper/ink/muted/line/soft/accent/tint/gold，但gold未形成明确角色，组件还用独立#色值。

## 主题适配与取舍

统一page/surface/text/text-secondary/border/accent/accent-soft/warning八个角色；warning只用于未知或需要确认的状态，绿不等同业务成功。

## 验收方式

样式不为第1到15章随机换主题色；相同未知状态颜色一致且有文字；新组件使用语义变量，不新增装饰色族。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
