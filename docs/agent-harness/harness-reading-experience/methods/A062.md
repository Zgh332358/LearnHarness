# A062 · 只给关键边界加提示框

类别：强调预算。决定：调整采用。

## 来源方法

[Carbon: Notification](https://www.carbondesignsystem.com/building-blocks/core/components/notification/guidelines)

Carbon callout 应少量使用；不要堆叠，普通内容使用正文。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

章学习目标、引用、实验状态、反馈、图解释都使用不同框线或底色；容易让页面成为连续提示框。

## 主题适配与取舍

关键任务边界保留一处提示；学习目标通过版式层级呈现，普通图解释回归正文。实验区可以有一个外框，内部不再为每个段落套卡片。

## 验收方式

普通段落不逐段卡片化；相邻提示区有不同职责且不重复；正文、图、实验的阅读顺序保持连续。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
