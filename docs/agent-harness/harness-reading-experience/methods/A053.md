# A053 · 章节跳转与实验动作使用各自语义

类别：交互语义。决定：调整采用。

## 来源方法

[Carbon: Button](https://www.carbondesignsystem.com/building-blocks/core/components/button/guidelines)

Carbon 将触发动作的按钮与导航链接区分。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

章节底部已用链接；顶部 reader-tools 使用按钮修改 hash，其他导航又使用链接。

## 主题适配与取舍

章节跳转优先保留可直接复制、打开的锚点链接；实验推进继续使用原生 button。若顶部仍用按钮，应保留可共享的目的地锚点。

## 验收方式

章节地址可复制后直达；实验动作不伪装成网页链接；键盘可独立完成两种任务。
