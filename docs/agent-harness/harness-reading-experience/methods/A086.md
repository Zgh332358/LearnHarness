# A086 · 必要边界和焦点指示有足够非文字对比

类别：颜色与视觉。决定：调整采用。

## 来源方法

[Understanding SC 1.4.11: Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

识别控件及状态所必需的视觉信息、理解图形所必需的部分，要与相邻颜色达到 3:1；纯装饰不在同一范围。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧自定焦点 #6a976b 在 tint #e2eddf 上约 2.785；细浅边框 #d5ded2/白约 1.369，不能独自承担输入识别。

## 主题适配与取舍

加深焦点环和必要输入边界；保留浅装饰分隔线，但给操作区使用明确文字、形状和必要的高对比边界。

## 验收方式

逐一记录自定焦点环、输入边界、必读箭头/状态标记与相邻背景的配对；必需项至少 3:1，装饰项不混作标准失败。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
