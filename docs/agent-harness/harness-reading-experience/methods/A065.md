# A065 · 读者不应把状态标签当成按钮

类别：状态视觉。决定：调整采用。

## 来源方法

[Carbon: Tag](https://www.carbondesignsystem.com/building-blocks/core/components/tag/guidelines)

Carbon 将只读标签与可选择、可移除标签分开，避免同一标签多种功能。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

阶段、未知、通过等状态目前是文字；若新增胶囊标签，很容易与选项控件形成相同外观。

## 主题适配与取舍

只读状态采用简短文字与细标记，不加指针、不加按钮阴影；可选择条件保留 radio/checkbox 或明确的控件外框。

## 验收方式

静态标签不会有点击暗示或进入 Tab 顺序；实际选项可操作性清楚；“未知”不能用弱灰表达成不存在。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
