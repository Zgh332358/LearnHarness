# A003 · 拒绝把拉丁文行距数字照搬为中文教材规则

类别：行距适配。决定：舍弃。

## 来源方法

[Butterick — Line spacing](https://practicaltypography.com/line-spacing.html)

作者用相同文本展示紧、适中和松行距，并建议无单位CSS行高。

证据类型：原作者教材原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

正文目前1.9，图内节点1.42；二者差异大，降低全文行高可能使图内汉字更拥挤。

## 主题适配与取舍

拒绝直接套用作者的1.2–1.45拉丁文范围；正文先试1.8–1.9，图内1.55–1.65，按钮1.25–1.4，按用途分开而不是共用。

## 验收方式

中文长段无上下字形碰撞；框内箭头标签换到两行也不叠字；正文调整不以缩短页面长度为唯一通过条件。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
