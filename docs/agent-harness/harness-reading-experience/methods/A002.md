# A002 · 用实际汉字行宽，而非全局容器宽度诊断长文

类别：正文宽度。决定：调整采用。

## 来源方法

[Butterick — Line length](https://practicaltypography.com/line-length.html)

作者以每行字符数判断行长，指出过长行难以回到下一行。

证据类型：原作者教材原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

main最大宽800px；按17px汉字粗估约47字，具体渲染宽度尚未测量。

## 主题适配与取舍

把普通叙述列设为约38–40个汉字宽的候选（约40em上限），图与表允许更宽；西文45–90字符建议只作参照，不认作中文标准。

## 验收方式

1440px宽屏统计两段中文正文每行约32–42个全角字；393px窄屏不强制固定行长；表格保留对照关系。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
