# A010 · 辅助信息可以安静，但不可缩成微字

类别：辅助文字。决定：调整采用。

## 来源方法

[Digital Scotland Typography](https://designsystem.gov.scot/styles/typography)

官方限制小字用途，并给出小屏14px、大屏16px参考。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

多处diagram标签.67rem默认约10.72px；这承载技术关系，不能当无关脚注。

## 主题适配与取舍

关键图内文字设不低于14px候选，必要时把图改为纵向或分组；真正元信息可13–14px，不通过缩字把多节点硬塞一行。

## 验收方式

所有箭头关系、结果状态和请求编号在100%缩放可读；393px时图文字不低于14px且不产生页面横向溢出。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
