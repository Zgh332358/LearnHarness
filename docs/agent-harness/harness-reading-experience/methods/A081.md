# A081 · Tab 聚焦时避开手机底部阅读栏

类别：焦点遮挡验收。决定：调整采用。

## 来源方法

[Understanding SC 2.4.11: Focus Not Obscured (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)

作者添加的内容不能让获得键盘焦点的组件完全被遮住；固定通知、顶栏尤其需要检查。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

新版拟增加手机底部位置栏。标题定位留白解决顶部跳转，不能替代逐项Tab到页面尾部控件的底栏遮挡检查。

## 主题适配与取舍

为主文尾部与视口底部设置阅读留白和 scroll-padding-bottom；实际以Tab/程序焦点模拟核查实验末尾按钮，不能只看标题锚点。

## 验收方式

390及320 CSS px宽，实验末尾控件聚焦后完整位于顶栏和底栏之间；缩放后重复。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
