# A057 · 整段选择文字可点，控件保持熟悉

类别：选择触达。决定：调整采用。

## 来源方法

[USWDS: Radio buttons](https://designsystem.digital.gov/components/radio-buttons/)

USWDS 推荐选项竖排、文字标签可选择，并保持选项样式一致。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

恢复选项为 .lab-choice 包裹 label，已竖排；字号、间距仍可统一，当前没有明显整行 hover/focus 反馈。

## 主题适配与取舍

保持原生圆形单选与完整文字标签；增加低强度整行选中边界及 focus-within，不使用模糊图标代替输入。

## 验收方式

点标签与点圆点结果相同；长选项逐行对齐；选中由控件和边界共同表示；键盘焦点不被背景色淹没。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
