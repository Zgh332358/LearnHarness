# A097 · 性能用加载、响应、稳定性分别量测

类别：性能与交付。决定：调整采用。

## 来源方法

[web.dev: Web Vitals](https://web.dev/articles/vitals)

Google 的良好体验建议为 LCP≤2.5s、INP≤200ms、CLS≤0.1，并以移动/桌面真实访问第 75 百分位评估。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧文件约 236KB，无运行时外部资源；这是轻量基础，但体积小不能证明三项指标已通过。

## 主题适配与取舍

不引入字体 CDN/重框架；记录新文件体积、资源请求与可用 Performance API 样本；本地样本注明环境，不声称线上第 75 百分位。

## 验收方式

项目体积预算设为 350KiB（可因明确功能调整）；无外部运行依赖；采集可取得的 LCP/CLS/交互延迟，缺项标未测，不以 Lighthouse 单分数替代实测。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
