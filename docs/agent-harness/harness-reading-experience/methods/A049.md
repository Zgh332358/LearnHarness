# A049 · 导航固定层不能遮挡正文与焦点

类别：定位可见性。决定：采纳。

## 来源方法

[Understanding SC 2.4.11: Focus Not Obscured (Minimum) | W3C](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)

官方解释指出固定头尾与持续展开的导航可能遮住键盘焦点，可用滚动留白等方式避免。

证据类型：标准解释（非规范性文档）。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现有 scroll-padding-top=28px 和 back-top 固定按钮适合旧布局；若新增顶部导航，其真实高度可能超过 28px。

## 主题适配与取舍

定位留白由新版固定栏高度控制，h2/h3/实验锚点均使用一致 scroll-margin；手机目录打开后不覆盖可继续聚焦的正文。返回顶部按钮避开实验操作区。

## 验收方式

在 390px、1280px 和 200% 缩放下逐一跳章/小节、Tab 到实验按钮，焦点组件始终至少部分可见；实际目标标题完整可见作为本项目更高要求。
