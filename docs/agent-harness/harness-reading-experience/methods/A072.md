# A072 · 代码与工作单有不同阅读提示

类别：代码密度。决定：调整采用。

## 来源方法

[Carbon: Code snippet](https://www.carbondesignsystem.com/building-blocks/core/components/code-snippet/guidelines)

Carbon 将行内、单行、多行片段区分，片段是只读内容。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

输入工作单、JSON 请求和伪代码都用 pre/code 软色块；非技术读者可能把全部内容当成必须运行的程序。

## 主题适配与取舍

为长块写清“输入工作单”“请求结构示例”“示意代码”；行内术语只轻度标记，JSON 采用舒适行距和低饱和语法色，保留可选择文本。

## 验收方式

每个长块不用读语法就知道用途；教学工作单不配运行按钮；关键字段清晰可读；手机长字符串可在自身区域处理。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
