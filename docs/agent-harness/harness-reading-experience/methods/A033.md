## 对当前教材的诊断

当前 h3 已有 section-N 等 ID，但标题旁没有显式复制或定位入口；现有 ID 已用于外部回看。

## 主题适配与取舍

保留现有 chapter-N、section-N、实验 ID；给小节加在悬停或键盘聚焦时显示的轻量链接入口，显示或复制含 hash 的当前位置。不为美化重编号旧锚点。

## 验收方式

旧 #section-9 和 #cycle-title 链接均仍可用；复制链接重新打开时展示所属章；链接图标的可访问名称含当前标题。
