# A023 · 拒绝用通用装饰插图填补“图文”

类别：装饰图取舍。决定：舍弃。

## 来源方法

[Digital Scotland Images](https://designsystem.gov.scot/styles/images)

官方要求图片回应理解需要，图片应补充文字而非替代必要信息。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

现有图解释请求、上下文和恢复；新增机器人、宇宙、科技球只能制造封面热闹。

## 主题适配与取舍

拒绝无教学作用的库存图或抽象AI大图；封面可用简短输入→判断→执行示意，且与正文术语一致；所有正文图都注明解决的问题。

## 验收方式

每个图能回答一个具体理解问题；删除图片时正文信息仍完整；新增图不得只以“更科技”解释存在理由。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
