# A020 · 不为营造书感强制全文衬线字体

类别：字体风格取舍。决定：舍弃。

## 来源方法

[USWDS Typography](https://designsystem.digital.gov/components/typography/)

官方把衬线长文、无衬线界面视为可选惯例，而非硬性规则。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前中文系统无衬线便携且一致；强制楷体或宋体会导致图、正文、英文多种视觉笔画体系。

## 主题适配与取舍

拒绝把英文字体惯例当中文结论；主正文维持可靠中文系统无衬线，书感通过纸面、比例和留白实现；代码用等宽字体。

## 验收方式

正文、操作说明和图中文字共享清晰字形；外部字体下载被阻断也不影响阅读；无手写/装饰字体承载关键说明。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
