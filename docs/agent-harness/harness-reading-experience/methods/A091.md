# A091 · 点击目标舒服，最低尺寸与例外明确

类别：缩放与响应。决定：调整采用。

## 来源方法

[Understanding SC 2.5.8: Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)

SC 的一般目标最低 24×24，存在间距、等效、行内、浏览器控制和必要布局等例外；44px 不是本条最低要求。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧阅读按钮 38px 高，实验 42px 高；相邻控件可操作但主要触控按钮还能更舒适。

## 主题适配与取舍

主要按钮和设置入口以至少 44px 高为项目舒适目标；标签整个区域可点；不将正文行内链接强制变成大块按钮。

## 验收方式

量测主要按钮至少 44px 高；非行内目标满足 24×24 或记录适用例外及间距；相邻控件不叠压。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
