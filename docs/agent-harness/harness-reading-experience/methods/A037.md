# A037 · 拒绝用自动无限滚动表达章节推进

类别：阅读节奏。决定：舍弃。

## 来源方法

[Pagination | GOV.UK Design System](https://design-system.service.gov.uk/components/pagination/)

官方说明提醒无限滚动会造成键盘导航问题，拆页应有明确可用性收益。

证据类型：官方组件说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

目前手动章节切换与可选全文展开已经给出明确节奏，无需自动滚到底加载或跳下一章。

## 主题适配与取舍

不增加滚动到底自动切章、不自动折叠已读内容。保留用户主动“继续阅读”和全文开关；读到章末时仍由读者决定下一步。

## 验收方式

滚到任一章末不会自行改变 hash、重置实验或切章；使用键盘的读者可在当前章末停留。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
