# A085 · 正文、辅助文案与链接都达到文字对比目标

类别：颜色与视觉。决定：调整采用。

## 来源方法

[Understanding SC 1.4.3: Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

普通文本最低 4.5:1，大字号文本可用 3:1；计算值不能四舍五入到刚好及格。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧 muted #667367 在 tint #e2eddf 上约 4.133，在 soft #eef2e9 上约 4.394，低于普通文字 4.5；主纸色上约 4.731。

## 主题适配与取舍

加深辅助文案色；为每个主题检查正文、注释、链接和卡片背景的配对，避免“精致浅灰”压低可读性。

## 验收方式

保存主题颜色配对计算表；所有正常使用的普通文字配对原始比值至少 4.5，不通过圆整凑阈值；例外需写明范围。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
