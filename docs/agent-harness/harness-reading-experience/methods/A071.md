# A071 · 窄屏表格按数据性质选择保留关系

类别：表格响应。决定：调整采用。

## 来源方法

[USWDS: Table](https://designsystem.digital.gov/components/table/)

USWDS 建议窄屏数值横向比较可滚动，目录式信息可堆叠，并尽量减少列。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

目前所有 reading-table 统一 min-width 540/570px 横向滚动；术语目录与角色比较都套同一处理。

## 主题适配与取舍

角色/阶段跨列关系保留滚动表格并给可见提示；术语、来源等目录可改成字段明确的堆叠行。只让表格滚动，不让整页溢出。

## 验收方式

窄屏能发现表格横向可读；滚动时角色列/表头语义仍可查；来源链接和术语不会被要求不断左右拖动；整页宽度等于视口。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
