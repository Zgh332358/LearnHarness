# A006 · 封面可有表现力，阅读和操作保持克制

类别：页面字级分区。决定：调整采用。

## 来源方法

[IBM Carbon Typography](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview)

Carbon区分表达型与任务型字级，避免产品操作被夸张标题干扰。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

封面46px，进入章节收缩为29px，已有两种情境；工具栏仍和正文使用近似重量。

## 主题适配与取舍

封面保留显著但不占满首屏的标题；内页书名作为安静的身份标识，章节标题为阅读焦点，按钮用任务字级，禁止每章重复大封面。

## 验收方式

进入第2章后首屏先看到章节问题与阅读内容；封面主标题明显高于辅助信息；工具栏文字不会视觉压过章标题。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
