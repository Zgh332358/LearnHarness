# A017 · 正文分节靠留白，边框只表达真实边界

类别：表面与边界。决定：调整采用。

## 来源方法

[IBM Carbon Spacing](https://www.carbondesignsystem.com/building-blocks/foundations/spacing/overview)

Carbon说明空白可形成内容区段，无需总靠线条分隔。

证据类型：官方设计系统指导原文核查。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

h2顶部线、chapter-map左线、figure框、节点框、实验框、反馈左线叠加，整书连续盒子感较强。

## 主题适配与取舍

取消普通正文的装饰性上边线，目标卡改为安静背景或短标识；保留工具执行边界、模型与存储区域、实验可操作区域等有语义的边框。

## 验收方式

正文连续两屏不被装饰框切碎；移除的线不曾表达系统隔离或方向；模型、工具、Harness关键边界仍可识别。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
