# A050 · 跳过导航直接进入正文

类别：键盘阅读。决定：采纳。

## 来源方法

[Understanding SC 2.4.1: Bypass Blocks | W3C](https://www.w3.org/WAI/WCAG22/Understanding/bypass-blocks.html)

官方说明让顺序键盘用户跳过重复导航，可更快抵达主内容；单页也可采用这一有益设计。

证据类型：标准解释（非规范性文档）。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

当前 body 先是封面与 18 个目录链接，没有跳过导航链接；键盘读者需经过多项导航再到正文。

## 主题适配与取舍

body 首个交互项加入“跳到正文”；聚焦时显现，激活后把焦点送到当前章节标题或 main。保留 main 和明确的导航 landmark，不用零尺寸隐身链接。

## 验收方式

首次 Tab 即显示跳到正文；Enter 后焦点位于可见正文，下一次 Tab 进入正文链接/实验而非重新遍历目录；不把单页采用此法等同宣布 WCAG 全面合规。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
