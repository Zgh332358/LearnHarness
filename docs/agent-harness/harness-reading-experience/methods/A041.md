# A041 · 先从同一实例开始，不让导航成为选择题

类别：主线规划。决定：调整采用。

## 来源方法

[Tutorials | Diátaxis](https://diataxis.fr/tutorials/)

作者强调教程围绕具体、可完成的学习经历，避免过早引入大量选择与支线。

证据类型：作者说明。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

本教材混合解释和实验，已有同一餐厅任务；导航美化时若加大量卡片入口，会把主线拆散。

## 主题适配与取舍

首屏仅突出“从第 1 章开始”和“打开目录”，把其他路线放次级区域；保留同一任务的章节顺序，不把四个实验替代为首页四个同等权重的产品卡片。

## 验收方式

新访客无需选择技术角色即可开始主线；首屏不超过两个主操作；目录仍可回查全部章节。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
