# A076 · 用明确 landmark 名称区分三种阅读区域

类别：结构与键盘。决定：调整采用。

## 来源方法

[W3C Technique ARIA11 — Using ARIA landmarks](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA11)

W3C Bypass Blocks 说明结构标记有助于绕过和定位页面区域；具体名称来自本项目导航分工。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版有 main 与一个完整阅读目录。新版加入章目录与本章路线后，若仍用同名 nav，会让结构回查失去区别。

## 主题适配与取舍

保留一个 main；整本目录标“全部章节”，当前章路线标“本章路线”，章节继续阅读保留自己的导航名；弹层目录也明确命名，不重复 main。

## 验收方式

DOM 中 main 仅一个；全部章节、本章路线、章节继续阅读三类导航有不同名称；此处不宣称真实读屏使用已通过。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
