# A067 · 阅读位置不能冒充学习完成率

类别：进度真实性。决定：舍弃。

## 来源方法

[USWDS: Step indicator](https://designsystem.digital.gov/components/step-indicator/)

USWDS step indicator 服务于线性过程，不适合任意顺序的交互。

证据类型：official-document-text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

文档允许目录跳章与全文模式，顶部进度条只表示浏览位置，不测理解。

## 主题适配与取舍

拒绝把18章画成已完成/未完成任务条或标为学习成功率；用“当前章节”“本章阅读位置”说明进度，目录支持自由回查。

## 验收方式

跳到附录不显示前文已掌握；刷新和滚动不被记录为测试通过；进度文字与实际计算范围一致。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
