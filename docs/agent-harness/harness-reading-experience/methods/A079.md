# A079 · 切章后焦点随阅读目标移动

类别：导航与键盘。决定：调整采用。

## 来源方法

[Understanding SC 2.4.3: Focus Order](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html)

当导航顺序影响理解或操作时，焦点顺序应保留意义；DOM 与动态焦点安排共同决定顺序。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧 showChapter 只滚动目标，不转移焦点；窄屏目录关闭后点中的链接可能处于隐藏内容内。

## 主题适配与取舍

用户明确点击章节或上下章时，把焦点移到该章标题；仅切换字号、主题或全文模式时保留操作焦点。

## 验收方式

从目录和上下章操作切章后，document.activeElement 是可见目标标题；后续 Tab 顺着本章；不使用正 tabindex。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
