# A083 · 可读名称、角色、状态与视觉一致

类别：浮层与状态。决定：采纳。

## 来源方法

[Understanding SC 4.1.2: Name, Role, Value](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html)

控件的名称和角色可被程序确定，用户可改的状态和值应可被确定和通知；标准控件按规范使用可减少额外工作。

证据类型：original_document_text。来源原页文本/示例核查；浏览器操作与成品验收另行记录。

## 对当前教材的诊断

旧版使用 label、fieldset 和 ARIA，但新增图标按钮或阅读设置可能只有视觉符号。

## 主题适配与取舍

所有设置写明可见名称；自定义展开控件同步 aria-expanded；当前章节同步 aria-current；图标不能独自承担名称。

## 验收方式

每个 button/input/select 有可确定的名称；全部 aria-labelledby/controls 指向存在且唯一的 ID；展开和章节状态与 DOM 可见性一致。

此条是研究与设计判断，是否实测及结果以总验收报告为准。
