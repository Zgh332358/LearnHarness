## 本轮发现并修正的问题

- 首次查找“系统位置”未命中“系统架构位置”：在标题索引中加入导航短名称，结果继续指向原文。
- 全文切换时隐藏标题的零坐标可能被选成阅读锚点：只在实际布局中的元素里定位。
- 全文开关只在正文起点，长章中途难以操作：移到持续可用的“阅读”设置。
- 搜索框 Escape 与弹层关闭、关闭事件与原文焦点存在竞争：显式关闭；取消时恢复触发器，选结果时进入原文。
- 手机“清空”被压缩折行：设置按钮不可收缩且禁止换行，保留输入框弹性宽度。
- 浏览器原生与脚本滚动恢复可能互相覆盖：明确采用手动历史恢复并实测后退/前进。
- 全文关闭后 URL 仍指向旧章，刷新回错章节：关闭时同步真实阅读锚点与状态，实测第 13 章刷新前后位置一致。

## 不将有限检查写成更大的结论

根字号放大到 36px 是 200% 文本渲染诊断，不是浏览器原生页面缩放测试。打印检查使用实际 print 媒体并触发打印前后事件，未验证系统打印窗口或导出 PDF 的分页。手机测试是 CSS 视口模拟，未使用物理手机；未完成 Safari/Firefox 或读屏器组合测试。

本机单文件加载样本约几十毫秒，仅证明当时本地加载状态；不作为线上 Core Web Vitals、弱网或低端设备保证。未开展真人读完教材后的理解测试，美学评分属于适配判断，不能称为统计研究结果。
