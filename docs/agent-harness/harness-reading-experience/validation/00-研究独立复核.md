## 验收可执行性与证据分级

大多数验收可以直接执行：DOM/ID/ARIA 对应核查、实际 hash 导航、键盘操作、局部滚动、指定宽度、颜色比值、真实打印介质、禁脚本加载，均有明确输入与可观察输出。未发现完全无法执行的验收条款。

有一组美学判断不是自动化通过项，需要记录为人工设计审阅，而非伪造测量数字：A006“不会视觉压过”、A009“只看标题复述”、A016“看成一组”、A017“连续盒子”、A023“每图解决一个问题”、A051“灰度主次”、A061“一眼能找到”。其中 A009 的“读者复述”若没有真实读者，改用“提取 h2/h3 顺序是否构成完整论证”做作者审阅，并明确尚未用户测试。

推荐给验收记录添加以下状态，而不是一律 passed：

1. **静态核查通过**：源代码、DOM 和颜色计算；不等于视觉或辅助技术已通过。
2. **浏览器操作通过**：保存操作、视口、结果及必要截图；源网站研究与本项目实测分开。
3. **人工设计审阅通过**：比例、留白、关系清晰度等判断，写理由与样本。
4. **未测/不适用**：真实读屏、未实际运行的平台、线上用户性能分位等不能推测为通过。

特别注意：200% 浏览器放大、320 CSS px 重排、修改正文设置字号不是同一实验；A088/A089/A090 应分别留证。A080 可见焦点、A086 非文字对比也不是同一标准。A085 中约数诊断须在正式验收保存未四舍五入的比值。
