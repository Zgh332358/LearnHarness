# 阅读体验与前端验收基线

核查日期：2026-10-07。本轮对象是已独立编写的 Agent Harness 教材 HTML，不使用仓库旧 DeepSeek 资料作为内容依据。

## 用户与任务

读者没有编程背景，但接受“输入、输出、执行”等具体技术词。读完应能解释运行逻辑、职责与部署位置，并知道当前产品怎样分工。正文 15 章、3 附录、9 图、4 个预设实验和 10 个自测保留；前端改造帮助找到内容、辨别层级和连续阅读。

用户要求联网参考前端文档，完成 100 轮诊断与美学方法整理，再结合教材主题自行选择最合适的一套方案。100 轮按有证据的不同设计问题计数，每条包括来源、当前诊断、选择及验收；不是 100 个网站、100 次真人测试或 100 张截图。

## 改造前观测

实际浏览器桌面 CSS 视口 1201×771，正文宽 800px、字号 17px、行高 32.3px。目录 18 个长标题处于同一层，没有本章小节目录、站内内容检索、字号选择和跳过导航。每章已有学习问题与描述性继续阅读链接，保留。

页面有章节单独阅读、全文展开、键盘控件、局部滚动表格和打印规则。它们不是待重写的空白功能，要针对具体缺陷改进。原色组部分辅助文字在浅绿色底上不足 4.5:1；若干图内文字约 11px；独立审阅指出全文滚动的高亮和 currentIndex 不一致，以及显式导航未迁移焦点。

## 设计判断

美学评估不是科学排名。比较阅读舒适度、主题匹配、信息层级、图与实验适配、中文与窄屏、实现与性能六项，由项目判断选择，不把分数冒充用户研究。先确定结构，再确定色彩与排版。全篇不做卡片墙，不用装饰性 3D，不自动播放；教学图与控件保留自己的语义。

## 验收目标

|维度|可检查条件|核查方法|
|---|---|---|
|完整性|18 阅读节、9 图、4 实验、10 自测；正文不丢失|文本与 DOM 对照|
|阅读层级|正文、章问题、图、实验有稳定且不同的层级|桌面与窄屏截图|
|导航|分组目录、本章路线、清楚当前位置；深链接可直接打开|实际点选与刷新|
|连续性|全文滚动后关闭全文留在当前章；前进后退恢复相应位置|实际操作|
|检索|关键词查找进入相应正文；空输入、无结果、清空有可见状态|实际输入|
|字号|标准/较大两档，不截字、不引起整页横向滚动|实际切换|
|窄屏|320/390/768/1024/1440 CSS 宽度均无页面水平溢出；必要表格在局部滚动|真实浏览器尺寸检查|
|键盘|Tab 可到核心控件，焦点明显；目录/搜索 Esc 关闭并回到触发按钮；跳过导航有效|实际键盘|
|对比|主要文字至少 4.5:1，组件/焦点至少 3:1；状态除颜色外有文字|颜色公式+检查|
|放大/间距|200% 阅读字号和 WCAG 建议文本间距设置下无内容丢失|浏览器渲染检查|
|实验回归|六事件、四检查请求、记录选择与组装、四恢复情境仍工作|实际分支操作|
|退化|无 JS 仍可读完整正文；打印正文全出；表格结构有 scope/caption|无 JS 与打印媒体核查|
|性能|无运行时外部依赖，控件无明显长任务；本地时间仅诊断，不称真实 Core Web Vitals|网络/性能数据|

这是一组针对本文件的验收项，不等于完整 WCAG 认证；未做真人学习研究、物理手机或其他浏览器全面兼容测试时明确说明。
